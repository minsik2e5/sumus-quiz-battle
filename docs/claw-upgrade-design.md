# 인형뽑기 퀄리티업 구성안 (V13.191)

선생님 요청 ① 놓침을 더 짜릿하게 ② 친구가 뽑은 걸 보기. (③ 3D · 물리 타당성은 따로: `docs/claw-3d-feasibility.md`, 초안 PR)
**서버 규칙(잡힐 확률 · 놓침 모양 비율 · 코인 · 하루 상한 · 집게권)은 그대로**다. 화면은 서버가 정한 결과를 받은 뒤 연출만 바꾼다.

## 1. 놓침 연출(near-miss)

연출 표는 `public/modules/claw-fx.js`의 `missPlan(res)` 하나가 정한다. 입력은 서버 응답의 `result` · `slip` · `grip` · `aim`뿐이다.
잡힘(`win`)이면 `null`이라 놓침 연출은 절대 나오지 않는다. "조준이 가까웠으면 더 아슬아슬, 멀었으면 허공"은 서버가 정한 조준(`aim`)으로 나눈다.

| 단계 | 상황(서버 결과) | 연출 순서 | 시간(ms) | 소리 | 진동 |
|---|---|---|---|---|---|
| **심쿵** heart | `slip: lift` + 조준 perfect · good, 또는 `slip: chute`(배출구 거의 다 와서) | 들어 올림 → **버팀**(인형이 발톱에서 2번 흔들림 · GRIP 숫자 떨림) → **멈춤** → 툭 · 솜털 12개 · SLIP! → **흔들림** → **슬로모션**(떨어지기 시작 ×0.45) → **한 박자 늦게** "아슬아슬! 아깝다!! 거의 잡았는데…" | 버팀 약 360~500 · 멈춤 95 · 흔들림 5px 200 · 슬로모션 240 → 530 · 문구 280 뒤 | 버팀 끼익 `claw-strain` → 툭 `claw-slip` → 아깝다 `claw-aww` | 버팀 [12,50,12] → [80,50,30,40,20] |
| **미끄러짐** slip | `slip: lift` + 조준 edge | 들어 올림 → 버팀 1번 → 멈춤 → 툭 · 솜털 7개 → 흔들림 → 슬로모션(×0.6) → "앗, 미끄러졌어요!" | 버팀 약 180~250 · 멈춤 70 · 흔들림 3px 160 · 슬로모션 260 → 390 · 문구 240 뒤 | 같은 세 소리 | [50,40,20] |
| **살짝 걸림** graze | `slip: loose`(쥐다 빠짐) | 살짝 들림 → 멈춤 → 툭 · 솜털 5개 → "살짝 걸렸다가 빠졌어요!"(edge: "끝에 걸렸다가 빠졌어요") | 멈춤 50 · 문구 200 뒤 | 툭 | [30,30,18] |
| **허공** air | `miss`(닿은 인형 없음 · 너무 빠른 집게) | 집게가 빈손으로 오므림 → 바닥 먼지 3개 → "앗, 허공을 잡았어요" | 문구 220 뒤 · 멈춤 · 흔들림 없음 | (없음) | [14] |

- 늘어나는 시간은 많아야 0.9초(`NEAR_EXTRA_MAX`)라 집게 하나 연출(서버 `ANIM_MS` 4.5초) · 다음 집게 간격(4초) 안에 든다(검사).
- 흔들림은 6px · 0.25초 이하로 짧고 빨리 사라진다. 멈춤 동안은 화면 전체의 반짝이 애니메이션도 같이 멈춘다(진짜 hit-stop).

## 2. 친구 소식(반 소식)

| 항목 | 정한 것 |
|---|---|
| 누구에게 | 같은 학교 · 같은 부 · 같은 학년(반은 달라도 됨). 전설 소식(`announceLegend` · `postLegend` · `legendFor`)과 같은 결 |
| 트리거 | 황금 인형 · 대박(두 개) · 도감 12종 완성 · 도감 6번째 새 인형(넘는 순간 한 번). 한 집게에 여럿이면 완성 > 황금 > 대박 > 6번째 하나만 |
| 문구 | "OO 학생이 황금 어흥 호랑이 인형을 뽑았어요!" · "OO 학생이 대박! 인형 두 개를 한 번에 뽑았어요!" · "OO 학생이 인형 도감 12종을 다 모았어요!" · "OO 학생이 도감 6번째 새 인형을 모았어요!" (이름 10자에서 자름) |
| 보이는 곳 | **놀이터 인형뽑기 화면 위쪽 한 줄**(📣 반 소식 · 문구 · "N분 전", 여럿이면 5초마다 넘김). 홈에는 넣지 않는다: 홈 위쪽은 선생님 공지 · 전설 소식 자리라 가리지 않게. 푸시 알림도 보내지 않는다 |
| 제외 | 비공개 학생(`ranking_public: false` · `share_profile: false`) · 선생님 미리보기 계정 · 쉬는 계정은 소식을 만들지 않는다(보기는 됨) |
| 개수 상한 | 학생 한 명 하루 2개 · 화면에는 최근 하루 3개 |
| 저장 | `state.clawNews`(최상위 키 → 백업 조각 `k:clawNews` 하나). 최근 50개만, 한 줄 `{ id, s, d, g, p, t, at }` → 가득 차도 약 10KB(검사 12KB 이하) |
| 응답 | `/claw/home` · `/claw/drop`(소식을 남겼을 때)에 `news: [{ id, text, at }]`만. 판 배치 · 좌표 · 조준 같은 힌트 없음 |

## 3. 성능 · 접근성

- 새 그림 · 새 라이브러리 없음. 솜털은 CSS 점(일부 기존 `fx-sparkle`), 한 번에 많아야 12개이고 0.7초 뒤 지운다.
- **동작 줄이기**(prefers-reduced-motion): 멈춤 · 슬로모션 · 흔들림을 없애고(계획에서 0), 버팀은 짧게, 솜털은 3개까지. 문구와 소리는 그대로라 뜻은 같다.
- **색만으로 구분하지 않는다**: 심쿵은 "아슬아슬!" 꼬리표 글자 · 큰 글씨 · 테두리, 소식은 📣 "반 소식" 꼬리표 글자.
- 소리를 끄면 진동도 끈다(기존 `buzz`와 같음). 아이폰(진동 없음)은 화면 흔들림 · 문구로 전한다.

## 4. 소리

| key | 뜻 | 길이 · 크기 |
|---|---|---|
| `claw-strain` | 놓치기 직전 집게 버팀(끼익 + 지잉) | 0.61초 · 5KB |
| `claw-slip` | 인형이 발톱에서 툭(스륵 + 폭신한 쿵) | 0.70초 · 6KB |
| `claw-aww` | 한 박자 늦은 "아깝다!"(반음씩 내려가는 말렛) | 1.29초 · 10KB |

기존 합성 방식(`docs/sound/claw-synth.mjs`, 낚시 `feel-synth.mjs` 재료). 합계 21KB → 효과음 전체 약 2.17MB / 상한 2.2MB(`sound-check`).

## 5. 검사 (`server/claw-upgrade-check.mjs`)

서버 규칙 숫자 그대로 · 서버 판정이 연출 표를 보지 않음 · 2만 번 굴린 서버 결과로 잡힘에는 놓침 연출 없음 / 허공은 인형을 들지 않음 / 놓침은 인형을 듦 ·
심쿵은 조준이 가까울 때만 · 늘어난 시간 상한 · 동작 줄이기 · 실제 `clawDrop` 응답 · 소식 트리거 · 하루 상한 · 비공개 · 미리보기 제외 · 같은 학년만 ·
하루 지나면 사라짐 · 저장 50개 · 12KB · 응답 모양(`id` · `text` · `at`만) · 화면 · 소리 · CSS 순서.
