## 제작과 확인

- 원본 주문서의 `STYLE REFERENCE`와 `WHEN DONE` 줄을 제거하고 지정된 참조 문장을 세 번째 줄에 넣어 생성했습니다. 저장소의 펫·아레나·UI 그림과 게임 스크린샷, 앞서 만든 정령·하늘 배경·하늘 소품을 시트별 참고 그림으로 사용했습니다.
- 다시 만든 횟수: 총 6회. 74-3·74-4·74-5는 잘림 또는 배경 혼입으로 각 1회 재생성, 74-6은 멀리 보이는 건물을 제거하기 위해 1회 수정, 74-14는 보스 성의 사나운 눈을 창문으로 바꾸기 위해 1회 수정했습니다. 74-1의 장애물 상자 제거도 1회 시도했으나 투명 경계 품질이 낮아 원래 후보를 채택했습니다.
- 원본 2×2 시트는 1024×1024, 배경 시트는 1024×1536으로 맞췄습니다. 14개 시트 모두 `slice-74.mjs --preview`를 경고 없이 통과했습니다.
- 미리보기에서 정령·장애물·성의 분리, 검정 바탕 빛의 더하기 합성, 네 길 타일의 세로 반복을 눈으로 확인했습니다. 그림에 글자·숫자·로고·체크무늬 배경은 없습니다.
- 눈으로 확인 필요: 테스트 앱 `/proto/runner-fx.html`에서 실제 화면에 정령·문·바위·성이 그림으로 바뀌는지, 움직이는 화면에서 길 타일의 이음매와 정령의 32px 가독성이 적절한지 확인해야 합니다.
