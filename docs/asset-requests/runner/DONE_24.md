## 눈으로 확인 필요

- 대표 시트의 캐릭터, 알 무늬, 표정, 전투 방향을 눈으로 확인했다. 60장 전체의 세부 외형과 기존 펫 그림체 일치는 PR 미리보기에서 최종 육안 검수가 필요하다.

## 점검

- 새 펫 그림 280개: 기본 크기 512×512, 작은 그림 160×160, 투명 모서리, 빈 그림 없음 확인.
- `slice-map.csv`의 그림 24 대상 파일 240개 전부 존재 확인.
- `npm ci`: 통과.
- `npm run build:assets`: 통과. 이 명령으로 `public/sw.js`가 갱신됐다.
- `npm run check`: 실패. 오류 메시지: `Error: [release-check] FAIL · V13.99 battle.js sends idx with choice and spelling answers and locks the word once sent`. 앱 코드와 점검 파일은 수정하지 않았다.
- `npm run check:cloudflare`: 통과. 로컬 모의 점검이며 운영 Supabase에 연결하지 않았다.

새 펫을 앱 코드에 등록하지 않았으므로 현재 앱 화면에는 변화가 없다. 버전은 올리지 않았다.
