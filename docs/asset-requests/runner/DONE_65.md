## 확인 결과와 눈으로 확인 필요

- 전체 9개 크기 및 용량 확인. 입구 220KB 이하, 배경·VS 각 200KB 이하.
- 배경 5개 완전 불투명, 배너·아이콘 4개 alpha 0~255 확인. 체크무늬·흰 상자·글자·숫자·로고 없음.
- 기존 전투 광장·야바위·벽·낚시·단어 매치·펫·리본·UI 트로피를 직접 보고 참고함. 기존 게임 고유 캐릭터·공·트레이너·체육관을 사용하지 않음.
- 390px 폭으로 축소한 3개 배경에 dog-2 펫을 90px로 6마리 합성해 펫 식별 확인. 전투 중앙에 장애물 없음.
- 경기장 세 장은 같은 링 배치로 맞추었으나 실제 폰 UI를 얹는 최종 확인 필요: 낮/숲 상단 12%는 밝은 꽃·햇살, 숲 하단 28%는 햇빛 반사가 남아 있어 체력바·단어 카드 대비를 확인해야 함. 게임 코드 미구현으로 최종 UI 대비는 확인하지 못함.
- 입구 카드 16:9 중앙 크롭 및 390px 폭 축소를 검토함.
- 최종 미리보기와 펫 합성은 검토용이며 저장소에는 포함하지 않음.
