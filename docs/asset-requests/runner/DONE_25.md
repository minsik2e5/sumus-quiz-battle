## 점검

- 넣지 못한 메달: 없음.
- 다시 만든 횟수: 각 시트 0회, 총 0회.
- 생성 시트는 투명 배경이며 글자와 숫자가 보이지 않는지, 메달 등급별 테두리와 중앙 소재가 주문서에 맞는지 확인했습니다.
- 눈으로 확인 필요: 앱 화면에서 48px로 표시되는 최종 식별성 및 기존 칭호와 나란히 놓았을 때의 등급별 테두리 일치 여부.
- 검사 결과: `npm ci`, `npm run build:assets`, `npm run check:cloudflare` 통과. `npm run check`는 `[release-check] FAIL · V13.99 battle.js sends idx with choice and spelling answers and locks the word once sent`에서 실패했습니다. 검사 파일은 수정하지 않았습니다.
