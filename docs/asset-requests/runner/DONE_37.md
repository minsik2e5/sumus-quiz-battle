## 생성 방식과 프롬프트

Codex 내장 이미지 생성 기능만 사용했다. 유료 API나 API 키, Google Drive, 운영 Supabase를 사용하지 않았다.

`split/37a-1`~`37a-6`, `37b-1`~`37b-21`, `37c-1`~`37c-9`의 각 원문을 사용했다. `STYLE REFERENCE`, `CHARACTER REFERENCE`, `Also open`, `WHEN DONE`으로 시작하는 줄을 제거하고 CODEX_PROMPT_37.md에 지정된 참고 첨부 문장을 세 번째 줄에 넣었다. 설정 → 잘라 넣기 → 해당 단계 참고 표정·알 반응 → 전투 순서로 진행했다.

- 설정 참고: 저장소의 panda-3, capybara-3, chinchilla-2를 열어 확인하고 첨부.
- 표정·알 반응 참고: 이번에 생성한 해당 펫·단계의 기본 WebP를 열어 확인하고 첨부.
- 전투 참고: 두 펫의 해당 단계 WebP 및 elephant-2-attack, elephant-2-hurt를 열어 확인하고 첨부. 코끼리는 자세·렌더링 참고로만 지정.
- 공통 보강: 칸별 넉넉한 투명 여백, 효과 포함 잘림·겹침 금지, 같은 해부학·무늬·소품 유지, 알에 얼굴 금지.
