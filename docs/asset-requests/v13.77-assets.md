### 1순위: 기뻐하는 얼굴
- 파일 이름: `{펫}-{단계}-happy.webp`
- 이미 앱 안에 **표정 칸**이 있어요. 지금은 핑키 2단계(`pig-2-happy.webp`) 하나만 있어요.
- 나머지 8종 × 3단계가 채워지면 쓰다듬기, 밥 주기, 승리 때 표정이 바뀌어요.

## 품질을 지키는 설정 (스튜디오 공통 스타일)
- **참조 이미지 고정**
  - 각 줄의 참조 이미지는 그 펫의 기존 그림(`{펫}-{단계}.webp`)이에요.
  - 앞에서 만든 결과물을 다음 줄의 참조로 이어 쓰지 마세요.
- **공통 스타일 문장** (CSV 프롬프트 끝에 이미 들어가 있어요)
  > 기존 SUMUS 펫 그림과 같은 화풍: 귀여운 치비 3D 일러스트, 부드러운 파스텔 색, 큰 반짝이는 눈, 은은한 림라이트, 캐릭터 정중앙, 테두리 여백 8%, 바닥 그림자 없음, 글자 없음
- **크기와 배경**
  - 펫: 512×512, 투명 PNG
  - 아이콘: 256×256, 투명 PNG
  - 앱 아이콘 마스터만 1024×1024 **불투명**이에요. 휴대폰이 모서리를 알아서 둥글려요.
- **후보 수**: 펫은 3장, 앱 아이콘은 4장. 제일 비슷한 것 하나를 승인하면 돼요.
- **파일 형식**: PNG로 주셔도 돼요. 제가 webp로 바꾸고 작은 미리보기(`-s.webp`, 160px)도 만들어요.
