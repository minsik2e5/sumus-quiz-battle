### CSV 열 → 스튜디오 항목
| 열 | 스튜디오 항목 |
|---|---|
| `name` | 이름 |
| `full_prompt` | 프롬프트(공통 스타일 문장 포함) |
| `reference` | 참조 이미지. 여러 장이면 ` ; `로 구분하고, **모두 고정**이에요. |
| `size` | 생성 크기 |
| `out` | 저장 크기 |
| `background` | 배경(`transparent` = 투명 PNG) |
| `count` | 후보 수 |
| `quality` | high |
| `project/id` | 폴더 |
| `file` | 앱 안의 최종 위치 |
| `after` | 이 항목의 마스터 id. 그 마스터가 승인된 뒤에 돌려요. |

## 작업 순서 (캐릭터 품질 무너짐 방지)
1. **phase 1**을 돌려요. 마스터마다 후보 4장이 나와요.
2. 한 장을 **승인**하고 `file` 경로 이름으로 저장해요(예: `public/assets/pets/penguin-2.webp`).
3. **phase 2**를 돌려요.
   - 모든 항목은 승인된 마스터나 기존 그림을 **고정 참조**로 새로 그려요.
   - 직전 결과를 이어 쓰지 않아요.
4. 결과 PNG를 폴더째 주시면 제가 해요:
   - webp 변환, 160px 미리보기 생성
   - 투명 배경과 발 기준선 확인
   - 앱에 연결

- 공용: 배경 4장, 체력바 틀, 타격·치명타 효과, 보상 상자(닫힘·열림)

## 참고
- 아직 앱 코드에 연결되지 않은 칸도 있어요: 새 펫, 새 로보, 보스, 이벤트 배너, 시즌 트로피.

- 스튜디오에 "공통 스타일"을 따로 넣을 수 있으면 `asset-manifest.json`의 `presets`를 쓰세요. 그때는 프롬프트로 `full_prompt` 대신 짧은 `prompt`를 쓰면 돼요.
