### 1-4. 미리 보기 계정의 "오늘 남은 판" 제안 (A11)

선생님 미리 보기 계정은 10초 맞추기를 하루 30판 할 수 있어서(`TIMING.PREVIEW_PLAYS`), 놀이터 요약에 "오늘 남은 판 60판"으로 더해집니다. 학생 화면과 달라 보여서 헷갈립니다.

- **권하는 방법**: 미리 보기 계정이면 요약 줄 끝에 "미리 보기 계정은 10초 맞추기 30판"을 작게 붙이고, 합계에는 학생과 같은 판 수(3~5판)만 더합니다. 화면 한 줄만 바꾸고 서버는 그대로입니다.
- 다른 방법: 미리 보기 계정의 판 수를 학생과 같게 낮춥니다. 대신 선생님이 여러 번 해 보기 어렵습니다.

## 2부. "AI 슬롭" 느낌 진단

버그를 다 고쳐도 남는 느낌입니다. 원인은 다섯 가지입니다.

### 2-1. 기준 없이 화면마다 새로 정한 값
앱의 CSS 묶음(1.2MB, 규칙 약 14,000개)을 세어 보면 이렇습니다.

| 무엇 | 지금 | 잘 정리된 앱 |
|---|---|---|
| 글자 크기 값 | 189가지 (12 · 12.5 · 11 · 11.5 · 10.5px가 다 쓰임) | 5~7단계 |
| 둥근 정도 값 | 150가지 (12 · 14 · 16 · 18 · 20 · 22 · 24px가 다 쓰임) | 3~4가지 |
| 색 | 2,388가지, 초록 계열만 약 100가지 | 이름 붙은 색 15~20개 |
| 그림자 | 836가지 | 2~3단계 |
| 그라디언트 | 1,437번 | 강조할 곳 몇 군데 |
| 글자 굵기 | 22가지 (700 · 750 · 800 · 850 · 900 · 950) | 3가지 |
| 토큰 묶음 | 8종이 따로 있음: `--sumus-*` · `--yl-*` · `--mh-*` · `--hd-*` · `--t-*` · `--rn-*` · `--a-*` · `--ya-*` | 1종 |

한 화면 안에서도 섞입니다. 홈은 글자 크기 17가지 · 둥근 정도 10가지, 야차전 몬스터 탭은 16 · 11가지, 놀이터 미니게임은 15 · 11가지입니다. 눈은 12px와 12.5px를 구별하지 못하지만 "어딘가 안 맞는다"는 느낌은 받습니다.

### 2-2. 뜻 없는 영어 꼬리표
제목 위에 작은 영어 대문자를 붙이는 것은 AI가 만든 화면의 흔한 버릇입니다. "PLAYGROUND / 놀이터", "LEARNING / 학습", "MY SUMUS / 나", "PET DEX / 펫 도감"처럼 **같은 말을 두 번** 합니다. 고1 학생에게 정보가 되지 않고, 화면마다 색도 다릅니다(초록 · 빨강 · 주황 · 보라 · 파랑). 로고와 NEW · MAX처럼 뜻이 있는 말을 빼고 22종을 찾았습니다. 이번에는 놀이터 첫 화면 카드 5곳과 MONSTER LEVEL만 뺐습니다.

### 2-3. 이모지 + 3D 그림 + 선 아이콘이 한 화면에
- 3D 그림 아이콘(주문서로 그린 것): 아래 메뉴, 나 화면 타일, 놀이터 카드
- 이모지: 놀이터 게임 카드의 숫자 줄(🎮 🔥 🏆), 기록 탭(🃏 🧱 🏟️ 🎯), 던전 탭(⚔️ 🏆 🔒), 선생님 대시보드(📢 🎉 🎯 🎮)
- 선 아이콘: 선생님 화면, 화살표, 뒤로 가기

세 가지가 한 화면에 같이 나옵니다. 이모지는 폰마다 모양이 달라서(아이폰 · 갤럭시) 더 들쭉날쭉합니다. 펫 아레나는 #298에서 이모지를 없앴는데 다른 화면은 그대로입니다.

### 2-4. 모든 것이 카드, 위계가 없음
- **홈**: 펫 카드 · 돌보기 버튼 2개 · 안내 줄 · 알약 3개 · 출석 · 연속 학습 · 랭킹이 모두 비슷한 무게입니다. "오늘 할 일 하나"가 눈에 안 띕니다.
- **놀이터**: 지갑 카드 → 요약 카드 → 큰 카드 4개. 요약 카드와 큰 카드가 같은 숫자를 다시 말합니다(A5).
- **야차전 대결**: 한 카드 안에 방식 · 단어 · 범위 · 판돈과 "?" 도움말 5개. 그 아래 버튼이 5개 더 있습니다.
- **나**: 타일 4개와 메뉴 6개가 같은 일을 나눠서 합니다(내 펫 · 펫 도감 · 칭호 도감이 타일, 내 기록 · 출석이 메뉴).

### 2-5. 탭을 바꿀 때마다 다른 앱
만든 시기마다 분위기가 다릅니다.

| 화면 | 만든 때 | 분위기 |
|---|---|---|
| 홈 · 학습 · 나 | v13.26~13.68 | 흰 카드 + 초록, 영어 꼬리표 |
| 야차전 대결 | v13.132 | 밝은 초록, 자체 토큰 `--yl-*` |
| 야차전 몬스터 | v13.94~13.174 | 보라 어두운 카드 |

### 2-6. 잘된 곳 (그대로 둘 것)
- 펫 그림 · 3D 아이콘 · 게임 배경 그림은 품질이 좋고 그림체가 맞습니다.
- 펫 아레나 #298의 토큰(`--a-*`)은 색 · 글자 크기 · 둥근 정도가 단계로 정리돼 있습니다. 넓힐 바탕으로 쓸 만합니다.
- 선생님 화면은 학생 화면보다 일관됩니다. 폰 폭 버그만 고치면 됩니다.
- 선생님이 "퀄리티 높게"라고 한 연출 · 이펙트(야차전 전투, 알 부화, 펫 아레나, 펫 대행진)는 이번 점검에서도, 구성안에서도 손대지 않습니다.

### 3-1. 세 방향

### 3-2. 공통 토큰 (A안 기준)

**색 — 이름 13개**

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `--bg` | `#f5f7f6` | 화면 바탕 |
| `--surface` | `#ffffff` | 카드 |
| `--line` | `#e2e8e5` | 테두리 · 구분선 |
| `--ink` | `#16221e` | 제목 · 본문 (흰 바탕 16:1) |
| `--sub` | `#57655f` | 설명 글 (흰 바탕 6.2:1) |
| `--brand` | `#0b7a54` | 주 버튼 · 선택 (흰 글자 5.4:1 — 지금 `#0e8a5f`는 4.36:1) |
| `--on-brand` | `#ffffff` | 주 버튼 글자 |
| `--soft` | `#e7f4ee` | 선택된 칩 · 연한 강조 바탕 |
| `--on-soft` | `#0a5c40` | 그 위 글자 (7.5:1) |
| `--coin` / `--coin-bg` | `#8a5a00` / `#fff4d6` | 코인 숫자만 |
| `--danger` | `#b42318` | 오답 · 경고만 |
| `--tile` | `#f1f5f3` | 그림 아이콘 받침 |

- 초록은 하나입니다. 지금 약 100가지 초록(`#07815f` · `#12b886` · `#0e8a5f` · `#17c487` …)을 `--brand` 하나로 모읍니다.
- 빨강 · 주황 · 보라 · 파랑 꼬리표 색은 없앱니다. 색은 뜻이 있을 때만 씁니다(코인 = 금, 오답 = 빨강, 등급 = 펫 등급 색).
- 펫 등급 색 · 리그 색 · 게임 속 색은 그대로 둡니다.

**글자 크기 — 5단계 + 숫자용 1**

| 이름 | 크기 | 쓰는 곳 |
|---|---|---|
| `--fs-1` | 12px | 설명 · 칩 (가장 작은 글자. 지금 7~11.5px는 모두 12px로) |
| `--fs-2` | 14px | 본문 · 버튼 보조 |
| `--fs-3` | 16px | 카드 제목 · 주 버튼 |
| `--fs-4` | 20px | 큰 카드 제목 · 숫자 |
| `--fs-5` | 26px | 화면 제목 |
| `--fs-num` | 32px | 홈의 큰 숫자 하나 |

굵기는 3가지(500 · 700 · 800)만 씁니다.

**둥근 정도 — 3가지**: `--r-1` 10px(버튼 · 입력 · 작은 타일), `--r-2` 16px(카드), `--r-pill` 999px(칩 · 알약).

**그림자 — 2단계**: 카드 `0 1px 2px rgba(16,34,30,.06)` + 1px 테두리, 떠 있는 것(창 · 아래 메뉴) `0 8px 24px rgba(16,34,30,.12)`. 그라디언트는 게임 안쪽과 "오늘 할 일" 카드 한 장에만 씁니다.

**간격**: 4의 배수(4 · 8 · 12 · 16 · 24). 화면 좌우 16px, 카드 안 14~16px, 카드 사이 12px.

### 3-3. 카드 · 버튼 · 칩 규칙

- **카드**: 한 가지 모양(흰 바탕 · 1px 테두리 · 16px · 그림자 1단계). 한 화면에서 강조 카드는 **한 장만**(오늘 할 일).
- **버튼 3가지**
  - 주 버튼: `--brand` 바탕, 높이 48px, 화면에 하나.
  - 보조 버튼: 흰 바탕 + 테두리, 높이 44px.
  - 글자 버튼: 글자만. 누르는 자리는 44px(안 보이게 넓힘).
- **칩**: 알약 모양, 12px 글자. 고른 것은 `--soft` 바탕 + `--on-soft` 글자. 색 칩(빨강 · 보라)은 쓰지 않습니다.
- **누름 영역**: 모두 44px 이상. "?" 도움말은 20px 동그라미 대신 줄 끝의 "도움말" 글자 버튼 하나로 모읍니다(야차전 대결은 "?"가 5개).
- **꺼진 상태**: 글자 `#8a9690`(흰 바탕 3:1), 바탕 `--tile`. 지금은 꺼진 글자가 1.4:1이라 안 보입니다.

### 3-4. 화면 뼈대 규칙

1. 화면 제목은 한글 한 줄(26px). 그 위 꼬리표는 없음.
2. 제목 아래 "지금 할 일" 한 장.
3. 나머지는 같은 모양 카드 목록. 같은 숫자는 한 번만.
4. 아래 메뉴는 지금 그대로(3D 그림 아이콘 유지).

### 3-6. 이모지 정리

### 3-8. 선생님께 여쭐 것

1. 방향: **A안(권함)** · B안 · C안 중 무엇으로 할까요? 게임 안쪽만 B안 계열로 두는 조합이 괜찮을까요?
2. 영어 꼬리표를 모두 빼도 될까요(로고와 NEW · MAX는 남김)?
3. 이모지를 그림 · 선 아이콘으로 바꿀 때, 몬스터 지역 이름 앞 이모지("🏫 야자 교실")도 바꿀까요?
4. 가장 작은 글자를 12px로 올리면 칭호 도감 · 내 펫 고르기 카드가 한 줄에 3개 → 2개로 줄 수 있습니다. 괜찮을까요?
5. 미리 보기 계정의 "오늘 남은 판" 표시(1-4)는 권하는 방법으로 할까요?
6. 320px 폰(아주 작은 화면)을 쓰는 학생이 있나요? 없으면 A12는 미룹니다.
