시안 C · 홀로 도감

펫을 "수집 카드"로 다룹니다. 진주빛 바탕에 먹색 테두리, 반짝이는 홀로 색은 펫과 보상에만. 제목은 각진 세리프(함렛)로 소장품 느낌. 공부한 단어도 카드 한 장씩 모입니다. ← 시안 목록

색 5개 + 홀로

  • 진주 #eeedf3 바탕
  • 먹보라 #1c1a27 글자 · 테두리 · 주 버튼
  • 종이 #fbfaf7 카드 안쪽
  • 금 #b8892a 등급 · 카드 번호
  • 체리 #d9434b 도장 · 오답
  • 홀로 그라데이션: 펫 그림 뒤 · 보상 · 고른 표시에만

글꼴 2개

  • 제목 · 숫자 · 단어: 함렛(Hahmlet) 600 · 700 · 800, SIL OFL 1.1
  • 본문: Pretendard 500 · 700 · 800, SIL OFL 1.1
  • 글자 단계: 12 · 14 · 17 · 20 · 32 · 46

모양 · 움직임

  • 카드 한 종류: 둥근 16, 먹색 1.5px 테두리, 안쪽 그림 칸. 카드 안 카드 없음
  • 카드는 살짝 기울여 놓음(−5°~9°). 홈은 3장이 부채처럼 펼쳐짐
  • 정답이면 단어 카드가 뒤집히고(520ms) 빛 한 줄이 한 번 지나감, "수집" 도장
  • 계속 반짝이는 움직임 없음. 빛은 transform으로 한 번만

말투

  • 수집가 말투, 명사형: "도감 22 / 94", "오늘 단어 20장", "다음 카드"
  • 단어를 "장"으로 셉니다(공부 = 카드 모으기)

숫자 · 이름은 예시입니다. 펫 등급 이름(전설 · 영웅 · 희귀)은 앱의 실제 등급표에 맞춰 바꿉니다. 그림은 모두 저장소의 것입니다(public/assets).
