1하늘 모험

맑은 하늘 · 풀빛 언덕 위의 펫, 둥글고 도톰한 판. 공부는 야생 단어 몬스터와 마주침.

홈 · 단어 공부 2도감 노트

번호 · 배지 · 수집률이 홈의 뼈대, 못 만난 펫은 그림자. 단어도 도감에 번호로 등록.

홈 · 단어 공부 3트레이너 카드

홈 = 내 트레이너 카드 + 칭호 배지 상자 + 함께하는 펫 6마리. 야차전은 카드끼리 맞대결.

홈 · 야차전 4대결 명령

상태 창 · 대사 창 · 명령 칸. 홈도 "무엇을 할까?", 야차전은 답이 곧 공격 명령.

홈 · 야차전 5휴대용 게임기

바둑판 바닥 · 두 줄 테두리 창 · ▶ 커서 메뉴 · 한 글자씩 나오는 대사.

홈 · 단어 공부 6반짝 카드

펫 = 체력 · 특기 칸이 있는 반짝이는 카드. 알 상점은 알 깨기, 야차전은 카드를 내서 겨룸.
