## 조사에서 얻은 핵심 원리

1. 달라 보이게 하는 것은 색 · 여백이 아니라 ① 제목 글꼴 ② 버튼 모양 ③ 화면 뼈대입니다.
2. 화면마다 가장 큰 버튼은 하나, 그 색은 다른 곳에 쓰지 않습니다.
3. 홈 가운데는 캐릭터 자리, 메뉴는 가장자리로 보냅니다.
4. 버튼은 아래 단(4~6px) + 누르면 그만큼 내려감. 입체는 "누를 수 있는 것"에만 씁니다.
5. 카드는 한 화면에 한 종류 · 한 겹. 카드 안 카드 금지.
6. 글꼴은 제목용 1개 + 본문용 1개.
7. 움직임은 `transform` · `opacity`만, 한 번 돌고 멈춤. blur · backdrop-filter · 끝없는 애니메이션 금지.
8. 영어 꼬리표 · 이모지 아이콘은 모두 뺍니다. 아이콘은 저장소의 3D 그림 한 벌만.
9. 고등학생은 아기 같은 화면을 유치하게 느낀다는 지적이 있습니다(검색 요약일 뿐, 직접 확인 못 함).

**조사의 한계**: 조사 환경에서 GitHub · npm 말고는 거의 다 막혔습니다(Duolingo 디자인 가이드, 토스, 눈누, Game UI Database, 글꼴 공식 사이트 등). 게임 UI · 한국 앱 장은 대부분 [통념] · [검색] 표시입니다. 게임 화면은 한 장도 직접 보지 못했습니다. 목록은 research 7장.

## 글꼴과 라이선스

| 글꼴 | 라이선스 | 서브셋 크기(한글 2,350자 + 영문 · 기호, woff2) | 파일 |
|---|---|---|---|
| Bagel Fat One | SIL OFL 1.1 (google/fonts의 OFL.txt 확인) | 358KB | `docs/design-renewal-mock/fonts/bagel-fat-one-kr.woff2` + `BagelFatOne-OFL.txt` |
| Pretendard | SIL OFL 1.1 (npm `pretendard` 1.3.9의 LICENSE 확인) | 가변 432KB, 굵기 1개 약 170KB | `fonts/pretendard-var-kr.woff2` + `Pretendard-OFL.txt` |
| 주아(Jua) | SIL OFL 1.1 | 368KB + 17KB, 이미 `public/assets/fonts`에 있음 | 시안은 그 파일을 그대로 가리킴 |

- 서브셋 만든 방법: `pip install fonttools brotli` 뒤 `pyftsubset 원본.ttf --text-file=chars.txt --flavor=woff2`. 글자 목록은 KS X 1001 한글 2,350자 + ASCII + 자모 + 기호 몇 개. 원본은 google/fonts 저장소와 npm `pretendard`.
- **쿠키런체는 쓰면 안 됩니다**(게임 산업 사용 금지 조건, 2차 출처). 잘난체 · 넥슨 Lv.1 · 메이플스토리체 · ONE 모바일 POP 등은 "수정 금지" 조건이 있어 서브셋이 걸릴 수 있어 뺐습니다. Gmarket Sans · Paperlogy는 공식 페이지를 직접 못 열어 대안으로만 적었습니다.
- 지금 앱은 `font-family`에 Pretendard를 적었지만 파일은 싣지 않습니다(폰 기본 글꼴로 보임). 글꼴을 실으면 첫 방문 무게가 늘어나므로 선생님께 여쭐 것 4번에 넣었습니다.

## 스크린샷 찍는 방법

- 시안: `node docs/design-renewal-mock/shot.mjs` (일부만: `--only dir1`). `dir1~3.png`와 `compare-*.jpg`를 다시 만듭니다. playwright는 `/opt/node-tools/node_modules/playwright`를 찾아 씁니다(없으면 `PLAYWRIGHT=경로`).
- 주소에 `?still`을 붙이면 들어오는 움직임 없이 멈춘 화면이 됩니다(스크립트가 씀).
- "지금" 화면(`before/*.jpg`): `npm ci && npm run build:assets` 뒤 `node docs/app-audit.mjs --only s-home,s-quick-practice,s-yacha-battle,s-arcade --shots --out 폴더`로 찍어 JPG로 바꿨습니다. 테스트 데이터 로컬 서버이고 운영에는 연결하지 않습니다. 결과 화면은 연습을 끝까지 풀어야 해서 따로 스크립트로 찍었습니다(다 틀려서 0점 화면). **v13.243.2 때 찍은 것**이라 v13.245.0에서 화면이 바뀌었으면 다시 찍어야 합니다.
