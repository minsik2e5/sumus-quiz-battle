> **V13.197 바뀜: 전설 펫 학생당 1마리 제한을 없앴다.** 어디서든 아직 못 만난 전설만 나오고(같은 전설 중복 없음), 4종을 다 만나면 더 나오지 않는다. 상점 전설 알은 남은 전설만큼 여러 번 살 수 있다(15,000코인 그대로). 영웅 20마리 보상은 전설을 다 만났을 때만 코인. 자세한 것은 `CHANGES_v13.197.0.md`.

# 전설 알 (V13.182)

영웅 펫을 모으면 전설 펫을 만날 수 있는 길. 선생님 결정 그대로이고, 숫자는 `public/modules/core.js` 한곳에 있다.

## 규칙

| 항목 | 값 | 상수 |
|---|---|---|
| 영웅 보상 | 영웅 펫(`EPIC_PET_KEYS`) **20마리** 이상이면 전설 알 1개(학생마다 한 번) | `LEGEND_EGG_EPIC_NEED = 20` |
| 상점 가격 | **15,000코인**, 학생당 1개, 전설 펫이 있으면 못 산다 | `LEGEND_EGG_PRICE = 15000` |
| 알에서 나오는 것 | 갖고 있지 않은 전설 4종(`LEGENDARY_PET_KEYS`, 불새 같은 retired 제외) 중 **랜덤** 1마리. 직접 고르기 없음 | |
| 신화 | 나오지 않는다(전설 알은 신화를 굴리지 않는다) | |
| 전설 보유자 | 알 대신 **3,000코인 + 칭호 '전설의 주인'** | `LEGEND_EGG_COINS = 3000` |
| 기존 확률 | 코인 뽑기 0.5% · 천장 150 · 영웅 알 1% · 선생님 알 1% — 그대로 | |

## 지급 시점
- **영웅 20번째를 얻는 순간**: 상점 · 교환소(낚시 · 사냥)의 영웅 알, 코인 뽑기의 영웅 알, 선생님 알, 몬스터 사냥에서 잡은 펫. 서버가 그 자리에서 `grantLegendEgg`를 부른다(영웅 수는 `EPIC_PET_KEYS`로 센다, 한정 펫은 세지 않는다).
- 지급 안내는 홈 화면이 한 번 보여 준다(기기마다 한 번, `localStorage`).
- 열지 않은 알은 **알 상점 → 전설 알** 탭에 남아 있고, 언제든 열 수 있다. 어떤 전설이 나올지는 **열 때 서버가** 정한다.

## 소급 처리
- 배포 전에 이미 20마리 넘게 모은 학생: 홈 데이터(`GET /bootstrap`의 `legend_egg.due`)가 받을 차례라고 알리면, 화면이 `POST /legend-egg/claim`을 **한 번** 부른다.
- 매 요청마다 검사하지 않는다. 쓰기는 학생마다 한 번뿐이고(`e20`이 있으면 아무것도 안 한다), 저장도 작은 키 하나다.

## 전설 보유자 대체 보상
- 영웅 20마리를 모았을 때 이미 전설 펫이 있거나(학생당 1마리), 열지 않은 전설 알이 있으면 → 3,000코인 + '전설의 주인'.
- 알을 열기 전에 다른 곳(코인 뽑기 · 영웅 알 · 선생님 알)에서 전설을 만났으면, 알을 열 때 전설 대신 3,000코인.

## 가격 근거
| | 코인 | 비교 |
|---|---|---|
| 영웅 알 | 800 | 영웅 20마리를 알로만 모으면 16,000 |
| 전설 알(상점) | 15,000 | 영웅 알 약 19개 값. 영웅 20마리 길(16,000)보다 조금 싸서 "급하면 사고, 아니면 모으면 공짜" |
| 대체 보상 | 3,000 + 칭호 코인 120 | 상점 가격의 20%, 영웅 알 약 4개. 이미 전설이 있는 학생도 20마리 목표가 의미 있게 |

## 저장 키
`profile.legend_egg = { e20, buy, wait, key, open_at, coins, coins_at }`
- `e20`: 영웅 보상을 준 때(중복 방지) · `buy`: 상점에서 산 때(학생당 1개)
- `wait: 'epic'`: 열지 않은 전설 알(어떤 전설인지는 없다) · `key` · `open_at`: 열어서 나온 전설
- `coins` · `coins_at`: 대체 보상 코인(`rewardIncome`에 더해진다)
- 펫 기록에는 `{ legendary: true, legend_egg: 'epic' | 'shop' }`, 전설을 얻으면 기존대로 `lucky.legend_key/legend_at`과 학교 소식(`announceLegend`).

## 서버 경로
- `POST /legend-egg/claim` — 받을 차례면 지급(아니면 아무것도 안 함)
- `POST /legend-egg/open` — 받은 알 열기
- `POST /legend-egg/buy` — 상점에서 사서 바로 열기(대결에 코인이 걸려 있으면 거절)
