# 학습 화면 민트 통일 구성안 (어법 · 빈칸영작을 단어 학습에 맞춤)

선생님 결정: **기준은 단어 학습 화면, 대표색은 민트(`#12b886`)로 통일.** 어법(중등 · 고등)과 빈칸영작 전부. 너무 크면 PR을 나눠서 하나씩.

## 지금 상태 (폰 스크린샷 기준)
| 화면 | 이미 민트 | 아직 파랑 · 남색 |
|---|---|---|
| 단어 학습(기준) | 탭 · 진행바 · 숫자 · 버튼 전부 | 없음(어두운 카드는 남색이 아니라 짙은 청록) |
| 어법 목록 | 과 · 학년 탭, 하단 탭 | 남색 배너, 본문 번호 타일, "어법 선택형" 칩, 화살표 동그라미 |
| 어법 문제 | 아래 "문장 채점" 버튼 | 진행바, "1차 · 문장 학습" 칩, "SENTENCE 01" 라벨, 선택 칸 |
| 빈칸영작 | 탭, 아래 버튼 | 어법과 같은 파랑 · 남색(어법을 따라 만들어서) |

- 어법 목록 카드(`gx-card`, `grammar-range-head`, `middle-grammar-tabs-v1339`)는 어법 · 빈칸영작 · 고등 어법이 같이 쓴다: 이 CSS를 바꾸면 모두 같이 바뀐다.
- 어법 문제 화면 스타일은 `public/grammar-choice-sample.js`(JS 안 `gcv3-*`), 빈칸영작은 `public/blank-writing.js`(JS 안 `bw-*`). 둘 다 파랑 `#3f6df3` 계열.
- 앱 대표색: `--sumus-primary:#12b886`, 큰 버튼 그라데이션 `#17c487 → #0eb77c`(`.btn.primary`).

## 원칙
- 색 · 간격 · 둥글기는 공통 CSS 한 곳에서 정하고 화면은 그것만 쓴다.
- 정답 초록 · 오답 빨강 · 힌트 노랑 같은 의미 색은 유지하되, 민트와 헷갈리지 않게 정답 초록을 조금 진하게.
- 기능 · 규칙은 건드리지 않는다(색과 모양만). 기존 어법 검사 중 색 · 클래스를 확인하는 줄은 같이 고친다.
- 폰 390px 전후 스크린샷은 꼭 필요한 한두 장만.

## PR 순서 (각각 새 세션)
**PR 1 · 목록 화면 공통 (CSS만, 작고 안전)**
- 남색 배너를 **밝은 민트 배너**로(문제 영역이 넓어 보이게, 선생님 결정은 이 안으로 진행).
- 본문 번호 타일 · 상태 칩 · 화살표 동그라미를 파랑 → 민트.
- 대상: 중등 · 고등 어법 목록과 빈칸영작 목록 · Step 고르기가 한 번에.

**PR 2 · 문제 풀이 화면 (중간)**
- 어법(`gcv3`)과 빈칸영작(`bw`)의 JS 안 스타일을 공통 CSS 한 파일로 모으고 민트로 통일(진행바 · 칩 · 라벨 · 선택 · 포커스 · 결과 화면).
- 빈칸영작 입력감 개선(스크린샷에서 확인한 것): 입력칸을 밑줄형으로 가볍게(지금은 글씨보다 큰 상자), **키보드가 올라오면 아래 "확인" 버튼이 가려지므로 키보드 위에 확인 버튼**, 중복 표시("Step 2"와 "1/4"가 두 번씩) 정리, Step 1 문장 줄 간격 줄이기, 비활성 큰 회색 막대 줄이기.
- 어법은 매일 쓰는 화면이라 가장 조심: 동작 그대로, 색과 모양만.

**PR 3 · 허브와 마무리 (작음)**
- 학습 허브 카드(지금 단어 파랑 · 어법 보라 · 빈칸 초록)를 한 가족으로(구분은 아이콘과 pill로).
- 앱 전체에서 남은 파랑 훑기, 고등 학교별 어법 화면을 폰 크기로 확인.
