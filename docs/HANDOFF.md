# 인수인계 (2026-10-09, 컴퓨터를 옮길 때)

새 컴퓨터의 Claude는 이 문서와 `CLAUDE.md`, `docs/dungeon-design.md`를 먼저 읽는다. 이전 대화는 없으니 이 문서가 전부다.

## 0. 규칙 요약 (자세한 건 `CLAUDE.md`)
- 답변·PR·변경 기록은 한국어. **브랜치와 PR까지만 하고, 선생님이 "머지해"라고 할 때만 머지한다.** `sumus-voca-prod-deploy`에 머지하면 운영에 바로 배포된다.
- 운영 Supabase에는 연결하지 않는다. 버전을 올리면 루트에 `CHANGES_v<버전>.md`. 바뀐 규칙마다 `server/*-check.mjs`에 검사를 남기고 `npm run check` · `check:cloudflare` · `check:load` · `check:sql` 4개가 통과해야 한다.
- 기능마다 새 세션. 그림은 Codex(내장 그림 기능)가 만들고 주문서는 `docs/asset-requests/runner`(`build-runner.mjs`로 생성, `CODEX_PROMPT_NN.md` 지시서)에 있다.
- 선생님이 "퀄리티 높게"라고 한 화면·연출·효과음은 줄이지 않는다.

## 1. 새 컴퓨터 준비
- 필요: git, node(24), GitHub CLI(`gh auth login`, 저장소 `minsik2e5/sumus-quiz-battle`).
- `git clone` 후 `sumus-voca-prod-deploy`에서 새 브랜치를 만들고 `npm ci`. Windows(CRLF)면 `V13.99 …` 검사가 로컬에서 실패하니 추적 텍스트를 LF로 바꾸고 돌린다(`git ls-files -z public server docs | …sed -i 's/\r$//'`), **커밋에는 필요한 파일만 `git add`** 한다. `V13.82 five games a day`는 한국 시간 자정 10분 전에 돌리면 실패하는 시간 문제라 10분 뒤 다시 돌린다.
- 이전 PC의 `var/local-test-login.txt`(로컬 시험 계정)는 저장소에 없다. 로컬 앱 확인용 계정이 필요하면 새로 만든다. 로컬 실행은 `DATA_PATH=<복사본> PORT=<포트> node server/index.mjs`(원본 DB는 건드리지 않는다).
- `public/sw.js`는 빌드 결과(`npm run build:assets`)다. 충돌하면 기준 브랜치 것을 받고 LF 기준으로 다시 빌드한다.
- 디스크 여유를 확인한다(이전 PC는 한 번 가득 차서 작업이 멈췄다). `node_modules`는 `npm ci`로 언제든 다시 생긴다.

## 3. 확정된 결정 (자세히는 `docs/dungeon-design.md`)
- **등급**: 기본 16 · 영웅 16 · 전설 4(해치·별고래·기린·천마) · 신화 5(미호·청룡·백호·주작·현무) · 한정 5. 불새(`phoenix`)는 숨김(보유 0명). 새 펫 8종은 기본 4(개구리·삽살개·사슴·곰) / 영웅 4(물범·늑대·악어·문어)로 확정.
- **신화**: 모든 알에서 아주 낮은 확률(랜덤 알 0.1% · 영웅 알 0.2% · 선생님 알 0.1% · 코인 뽑기 0.03%), 천장 없음, 한정 알 제외. 전교 알림, 풀스크린 연출, 움직임 줄이기는 항상 지킨다.
- **이벤트 알**: 11/30까지. 야차전 할로윈 배경은 11/7까지만.
- **던전**("기말고사 지옥", 같은 학년 2~3명 실시간): 난이도 3등급 컷 → 2등급 컷 → 1등급 컷 → 만점(무한 층). 보기 4→5→6개, 층이 오를수록 제한 시간이 짧아지고 못 누르면 펫이 기절(동료가 3연속 정답으로 부활). 보스 킬러 골렘 3페이즈(빨간펜 채점 / 핵 노출). 몬스터는 일반 15종이 층마다 무작위로 나온다. 범위가 120단어 미만이면 이미 푼 앞 범위·추가 단어장·틀린 단어로 보충. 학년별·등급컷별·인원별 클리어 시간 기록(봇 낀 파티는 제외). **보스는 일반 몬스터보다 크게**(화면 폭의 약 70%).
- **효과음**: `public/modules/sound.js` + `public/assets/sfx/*.mp3` 26개, 출처는 `docs/sound-library.md`. 우리가 합성한 소리 + Kenney(CC0). Mixkit은 저장소가 공개라 원본을 올리지 않았다(재배포 금지 조항).

## 4. 보류 / 선생님이 정하기로 한 것
- **고등학생도 단어를 하나씩 골라 연습하게 하기**: 중학생은 연습 시작 화면에서 단어를 체크해 고를 수 있다(`A.middleWordIds`, `word_ids`). 고등학생은 범위(과)만 고른다. 선생님이 다른 컴퓨터에서 이야기한 적이 있다고 했지만 이 PC에는 기록이 없었다. **먼저 "어느 화면(연습 시작 / 단어 학습 / 몬스터전·던전)에 넣을지"를 선생님께 물어본다.**
- 빨간펜 귀신(그림 22): 붉은 잉크가 피처럼 보인다. 그대로 쓸지, Codex에 눈물·흘러내림만 지워 달라고 할지 선생님이 정한다.
- 효과음 고르기: 시청 페이지(`docs/sound-library.md` 참고, 후보 약 500개)에서 선생님이 순간별로 고르기로 했다. 고른 게 없어서 지금은 "새로 만든 소리"가 기본이다. 마음에 안 들면 같은 key의 mp3만 바꾼다.
- 선생님 알 선물로 나온 신화를 풀스크린 연출로 보여 주기(지금은 카드), 5마리를 다 모으면 "가을 수집가" 칭호(칭호 메달 그림 필요).
- 던전 코인 수치·하루 횟수(3회)·순위 공개 범위는 시뮬레이션 뒤 확정.
