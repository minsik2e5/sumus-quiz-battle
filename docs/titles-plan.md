- 칭호는 판정이 기록에서 바로 나오므로(`titleUnlocked`), 배포하면 조건을 채운 학생은 **바로 얻고**, 처음 볼 때 코인을 한 번 받는다(`/titles/seen` → `payTitles`, 이미 받은 key는 다시 안 줌). 따로 지급 작업은 없다.
- 많이 받는 학생 예: 본렙 75 · 몬스터전 50 클리어 · 빈칸 5과 완료면 한 번에 약 10개 · 380코인(하루 학습 상한 약 2.7일치, 한 번뿐).
- **알림 폭주 막기**(결정 5 추천): 지금은 새 칭호를 등급순 5개씩 팝업으로 보여서 여러 번 뜰 수 있다. 3탄 칭호 중 배포 전부터 조건을 채운 것은 **한 장 묶음 카드**("칭호 N개가 한꺼번에 도착! +N코인", 메달 작게 나열)로 한 번만 보여 주고, 그 뒤로 새로 얻는 것만 지금처럼 팝업한다. 푸시 알림은 보내지 않는다.
- **꼭 같이 고칠 것**: `p.titles_seen`(학생이 본 칭호 key)은 지금 **160개에서 잘린다**(`server/service.mjs` `/titles/seen`). 칭호가 123 + 펫 3 + 3탄 25 = 151개라 거의 다 모은 학생은 여유가 없고, Lv.105 이후 칭호가 계속 늘면 넘쳐서 본 칭호가 다시 "새 칭호"로 뜬다. 코드 세션에서 **240으로 올린다**(새 저장 없음, 배열 길이만).
