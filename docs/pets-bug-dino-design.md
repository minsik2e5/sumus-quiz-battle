# 곤충 · 공룡 펫 시리즈 구성안 (그림 주문서 54 · 55)

선생님 결정(정정본): **곤충 + 공룡 = 하나의 별도 시리즈.** 기존 전역 등급(기본 · 영웅 · 전설 · 신화 · 한정)에 섞지 않는다.
시리즈 **안에서** 일반 · 영웅 · 특이 · 전설 · 신화로 나눈다(시리즈 안 희귀도 · 세기 라벨, 테두리 색, 도감 구분). **특이**는 영웅보다 조금 센(+약 3%) 독특한 컨셉 펫이고, 희귀도는 영웅과 전설 사이다.
- **없는 것**: 새 재화, 화석 조각, 던전 · 사냥 · 낚시 조각 드롭.
- **있는 것**: 시리즈 전용 **알 하나**(코인으로 사는 알 상점 새 탭, 한정 알 · 전설 알 탭과 같은 결).
- 기존 알 · 전설 알 · 영웅 20마리 보상 · 도감 마스터 · 학생당 전설 1마리 제한 · 코인 뽑기 확률에 **영향이 없어야 한다.**

이번 세션은 **문서와 그림 주문서만** 만든다(게임 코드 · 서버 규칙 변경 없음). 등록 · 특기 숫자 · 시리즈 알은 그림이 온 뒤 다음 코드 세션에서 한다.

## 시리즈를 따로 두는 방법 (코드 세션용 설계)

- `CHARACTERS[key]`에 전역 등급 플래그(`epic` · `legendary` · `mythic` · `limited`)를 **넣지 않는다.** 대신 `series: 'wild'`, `rank: 'basic' | 'epic' | 'special' | 'legendary' | 'mythic'`, `group: 'bug' | 'dino'`, `artOrder: 54 | 55`.
- `core.js`의 전역 풀은 모두 `!c.series`를 더한다: `STANDARD_PET_KEYS`(지금은 "플래그 없음 = 기본"이라 이걸 빼면 시리즈 펫이 기본 알에 섞인다 — **가장 중요한 한 줄**), `EPIC_PET_KEYS`, `LEGENDARY_PET_KEYS`, `MYTHIC_PET_KEYS`, `LIMITED_PET_KEYS`. 새 목록 `WILD_PET_KEYS = readyKeys(c => c.series === 'wild')`, `wildRank(key)`.
- `petTier(key)`: 시리즈 펫은 `'wild'`(또는 `wild-<rank>`)를 돌려 전역 전설 · 신화 연출 · 소식(`announceLegend`) · 전설 보유 검사(`hasLegendPet`)에 걸리지 않게 한다.
- 그래서 바뀌지 않는 것: 기본 알 · 영웅 알 · 선생님 알 선물 · 코인 뽑기(전설 0.5% · 천장 150 · 영웅 3%) · 전설 알 · 영웅 20마리 보상 · '도감 마스터'(27마리 기준 그대로) · 학생당 전설 1마리 · 신화 굴림 · 한정 펫 '시즌 뒤' 길 · 몬스터 사냥 · 낚시/사냥 교환소.
- 전역 규칙 중 시리즈에 **적용하지 않는 것**: 학생당 전설 1마리(시리즈 전설은 따로 센다), 시리즈 알은 전역 신화를 굴리지 않는다(전설 알과 같게).
- 포함해도 되는 것(추천): 전체 펫 수(`ACTIVE_PET_KEYS`, "MY PETS n/m")와 '펫 n마리 만나기' 칭호. 한 마리는 한 마리라서. 원하지 않으면 `ACTIVE`에서도 뺀다.
- 야차전 · 파트너 · 꾸미기 · 레벨은 다른 펫과 똑같다.

## 시리즈 알 (알 상점 새 탭 "고대 탐험대 알")

- **가격 1,000코인**(선생님 결정, 영웅 알 800보다 비쌈), 하루 제한 없음(영웅 알과 같게). 대결에 코인이 걸려 있으면 못 산다(기존 알과 같은 검사).
- 열면: 남은 시리즈 펫이 있는 등급 칸끼리 무게(일반 60 · 영웅 30 · 특이 5 · 전설 0.7 · 신화 0.2)로 칸을 고르고, 그 칸의 안 가진 펫 중 랜덤. **이미 가진 펫은 안 나온다.** 12마리를 다 모으면 "고대 탐험대를 모두 모았어요!"로 막는다(기존 알의 409 안내와 같게).
- 그림이 안 온 펫은 풀에 없다(1차만 왔을 때는 일반 4 · 영웅 4뿐 → 다 모으기 8개 = 8,000코인).
- 열 때 서버가 정한다(전설 알처럼, 미리 정해진 펫 없음). 시리즈 전설 · 신화가 나오면 기존 영웅 펫 공개 연출, 신화는 신화 등장 연출(등장 포즈 · 배경)을 쓴다.
- 알 그림: `ui/wild-egg.webp`(그림 54d). 시리즈 배지 `ui/wild-badge.webp`도 같은 시트.

### 가격 · 확률 근거 (시뮬레이션 20만 번, 같은 규칙: 중복 없음, 1,000코인)

| 비교 | 평균 코인 | 중간값 | 빠른 10% | 첫 알에서 |
|---|---|---|---|---|
| 전역 전설(해치 등) — 전설 알 상점 | 15,000 | | | |
| 전역 전설 — 영웅 20마리 보상(영웅 알만으로) | 16,000 (+ 영웅 20마리) | | | |
| 전역 전설 — 코인 뽑기 | 0.5%, 150번이면 반드시 | | | |
| 전역 신화 — 모든 알 0.1~0.2%(천장 없음) | 기본 알 기준 약 400,000 | | | |
| **시리즈 특이(추천 60/30/5/0.7/0.2)** | **약 8,500 (8.5개)** | 9개 | 4개 | 5.2% |
| **시리즈 전설(추천)** | **약 10,500 (10.5개)** | 11개 | 9개 | 0.7% |
| **시리즈 신화(추천)** | **약 11,600 (11.6개)** | 12개 | 11개 | 0.2% |
| 시리즈 전설(다른 안 60/30/6/1/0.3) | 약 10,400 (10.4개) | 11개 | 8개 | 1% |
| 시리즈 신화(다른 안) | 약 11,500 (11.5개) | 12개 | 11개 | 0.3% |
| (참고) 앞 안 1,200코인 · 60/30/8/1.5/0.5의 시리즈 전설 | 약 12,100 | 11개 | 7개 | 1.5% |
| 시리즈 다 모으기 | 12,000 (12개) | | | |

- 중복이 없어서 최악도 12개(12,000)로 끝난다. 이게 천장 역할을 해서, 전설을 "운 좋으면 빨리, 아니면 시리즈를 거의 다 모을 즈음" 만나게 된다.
- 추천안은 시리즈 전설이 전역 전설보다 **조금 쉽고(약 70%), 훨씬 쉽지 않다.** 첫 3개(3,000코인) 안에 전설이 나올 확률 약 2%. 가격이 1,200 → 1,000으로 내려간 만큼 전설 · 신화 무게를 1.5 · 0.5 → 0.7 · 0.2로 낮춰, 앞 안(약 12,100)보다 조금 아래에 맞췄다.
- 특이는 영웅(30)과 전설(0.7) 사이(5): 평균 약 8,500코인, 첫 알 5%.
- 시리즈 신화는 전역 신화보다 훨씬 쉽지만, 전역 신화 풀 · 확률에는 영향이 없다(따로인 시리즈). 시리즈 안에서는 전설보다 늦게(평균 1개 더) 나온다.
- 중복이 없으면 시리즈 전설은 아무리 늦어도 12개(12,000코인) 안에 나온다. 1,000코인에서 전설을 더 어렵게 하려면 중복을 허용해야 하는데(중복은 코인 일부 돌려주기 등), 규칙이 복잡해져서 추천하지 않는다.
- 숫자는 `core.js` 한곳의 상수(`WILD_EGG_PRICE`, `WILD_EGG_WEIGHTS`)로 둔다.

## 그림이 와야 나온다 (게이트)

- `artOrder: 54 | 55`로 등록하면 `petReady`가 그림이 다 있는 펫(기본 · 작은 그림 · 표정 · 알 반응, 신화는 등장 포즈 · 등장 배경까지)만 `WILD_PET_KEYS`에 넣는다(`readyKeys`). 그림이 한 장이라도 빠지면 그 펫은 시리즈 알에도 도감에도 없고 "곧 만나요" 그림자 칸에만 나온다.
- 시리즈 알 탭은 `WILD_PET_KEYS`가 비어 있거나 `ui/wild-egg`가 없으면 숨긴다.
- 그림 PR(Codex)은 펫이 core.js에 없을 때 머지돼도 안전하다: `build:assets`가 `pet-art.js`의 `PET_ART`에 키를 넣어도 `CHARACTERS`에 없으면 `petReady`가 거짓이다.
- 1차만 먼저 와도 1차 8마리 + 시리즈 알을 열 수 있다. 2차는 그림이 오면 자동으로 알 풀에 들어간다.

## 이미 펫을 가진 학생

- **영향 없음.** 가진 펫 · 레벨 · 파트너 · 꾸미기 · 특기 · 전역 등급 진행(영웅 수 · 전설 알 · 도감 마스터)은 그대로다. 저장 형식도 바뀌지 않는다(시리즈 펫도 기존 `pets[]` 기록 하나씩, `{ series: 'wild' }` 표시).
- 이미 전역 전설이 있는 학생도 시리즈 전설 · 신화를 얻을 수 있다(별도 시리즈).

## 도감(petbook) 표시

- 전역 섹션(기본 · 영웅 · 전설 · 신화 · 한정) 아래에 **"고대 탐험대" 섹션**을 따로 둔다. 진행 "n/12"와 시리즈 배지(`ui/wild-badge`).
- 섹션 안은 시리즈 등급 순(일반 → 영웅 → 특이 → 전설 → 신화). 카드 테두리 색은 같은 이름의 전역 등급 색을 빌리고(특이는 영웅 보라에 금빛 점), 카드에 작은 태그 **`곤충`** · **`공룡`**과 시리즈 등급.
- 선생님 도감 요약에도 "고대 탐험대 n"을 한 칸 더한다.

## 칭호 자리 (나중에 칭호 4탄)

- 이번에는 **자리만** 정해 둔다. 그림 주문에는 칭호 메달을 넣지 않았다(60번부터 칭호 4탄용).
- 후보: **곤충 박사**(시리즈 곤충 6마리) · **공룡 박사**(시리즈 공룡 6마리) · **고대 탐험대 완성**(12마리, 시리즈 도감 완성 보상). stat 자리: `wild_bug` · `wild_dino` · `wild_pets`(titleStats).
- 시리즈 도감 완성 보상은 이 작은 칭호(코인은 칭호 코인 표 그대로)만. 다른 보상(재화 · 알)은 없다.
