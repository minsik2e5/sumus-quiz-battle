# SUMUS VOCA 디자인 컨셉 다시 정하기 — 고등학생 기준 (2026-11-21)

시안: `docs/design-concept-mock/index.html`(10방향 목록) · 그림 · 영상: `docs/screenshots/design-concept/` (모음 `all-1.jpg` · `all-2.jpg`, 방향별 `dir-NN-*.jpg`, 영상 `tour.mp4`, 01~03 비교 `compare-*.jpg`)
실제 앱 코드(`public/`, `server/`)와 버전은 건드리지 않았습니다.

## 결론 먼저

1. **지금 앱이 "AI가 만든 것 같다"는 느낌은 색보다 "모든 것을 같은 무게로 늘어놓기" 때문입니다.** 홈 한 화면에 글자 크기 17가지, 둥근 정도 10가지, 그림자 13개, 영어 꼬리표, 알약 칩, 카드 안 카드가 다 있습니다(5장).
2. **고등학생이 실제로 매일 보는 화면(인스타 · 틱톡 · 디스코드 · 로블록스 · 대전 게임)은 어둡거나 한 색이 아주 진하고, 글자가 크고, 한 화면에 할 일이 하나입니다.** 국내 1위 학습 앱(말해보카 · 스픽 · 콴다)도 "한 색 + 아주 굵은 큰 글씨 + 흰 문제 화면"입니다. 귀여운 캐릭터는 쓰지만 화면 틀은 어른스럽습니다.
3. **선생님이 느낌을 보고 고르시도록 10방향을 만들었습니다.** 방향마다 홈 화면 1개 + 색 · 제목 글꼴 · 버튼 견본. 그중 01~03은 단어 공부 · 야차전까지 3화면을 미리 만들었습니다. 모두 지금 앱(흰 바탕 · 민트 · 둥근 카드)과도, 지난 시안(게임 로비 · 모험 지도 · 큰 글자 미니멀)과도 다릅니다.

## 3. 해외 학습 앱 · 10대가 좋아하는 게임

| 이름 | 표시 | 왜 멋있어 보이나 (글자 · 기울기 · 색 수 · 여백 · 움직임) | 가져올 원칙 |
|---|---|---|---|
| Quizlet · Kahoot · Memrise · Drops | 직접 봄 | Kahoot: 보기 4개를 색 · 도형으로 구분. Drops: 짙은 보라 + 그림 하나 + 단어 하나. Memrise: 노랑 한 색 + 실제 사람 영상 | 보기는 "번호"로 구분(색 4개 남발 대신) |
| Brilliant | 직접 봄 | 따뜻한 회백 바탕, 세리프 기울임 제목, 초록 정답 하나 | 세리프 제목도 공부 앱에서 어른스럽게 보인다(C) |
| Forest · Habitica · Finch | 직접 봄 | Forest는 키운 숲이 "결과물"로 쌓임. Finch는 파스텔 · 동글 — 고등학생에겐 어려 보임 | **쌓인 결과를 한눈에**(C 도감 칸). 파스텔 동글은 피함 |
| 브롤스타즈 · 클래시 로얄 | 직접 봄 | 캐릭터가 틀 밖으로 크게 나옴, 아주 굵은 글자 + 두꺼운 외곽선, 사선 구도 | 캐릭터는 크게 · 잘려도 됨. 굵은 글자는 제목에만 |
| 젠레스 존 제로 | 직접 봄 | 검정 + 형광 주황 · 노랑, 기울어진 패널, 굵은 사선 글자, 거리 스티커 · 테이프 느낌 | **기울기 하나(−12°)를 모든 버튼 · 막대에 통일**(A) |

| 쿠키런 킹덤 · 메이플스토리 M | 직접 봄 | 캐릭터 · 이펙트가 화면 가득, 금색 테두리 · 굵은 글자 · 색 많음 | 고등학생에게는 "옛날 모바일 게임" 느낌이 날 수 있어 색 수를 따라가지 않음 |
| 페르소나 5 · 스플래툰 3 | 못 봄 | [통념] 페르소나: 빨강 · 검정 · 흰 3색, 오려 붙인 글자, 메뉴가 기울어 날아듦. 스플래툰: 형광 2색 대비, 잉크 얼룩 | A의 "3색 + 기울기 + 빠르게 날아듦"과 같은 방향 |

**공통으로 나온 "멋있어 보이는" 원칙 6가지**
1. 강조색은 **하나**(많아도 둘). 나머지는 검정 · 흰 · 회색.
2. **기울기를 하나 정해 통일**하면 바로 "게임 화면"이 된다(젠존제 · 발로란트 · 포켓몬 챔피언스).
3. 캐릭터는 **틀 밖으로 크게**, 잘려도 된다. 테두리 안에 가두면 아기 앱처럼 보인다.
4. 글자는 **아주 큰 것 하나 + 작은 것** 두 단계가 기본. 중간 크기가 많을수록 흐려진다.
5. 칸은 카드보다 **선과 면 색**으로 나눈다(토스 · 발로란트 · 로블록스).
6. 움직임은 **짧고 세게, 한 번** — 계속 반짝이지 않는다.

## 6. 컨셉 10방향

01~03은 홈 · 공부 · 야차전 3화면, 04~10은 홈 1화면 + 견본입니다(선생님이 고르시면 2단계에서 3화면 · 영상 · 비교 그림을 만듭니다).

시안 HTML 아래쪽에 같은 규칙표가 있고, 토큰은 각 파일 `<style>` 맨 위에 있습니다.

### 01(A) · 스트릿 HUD — `a-street.html`
- **한 줄**: 검정 바탕에 빨강 한 색, −12° 기울어진 굵은 글자. 대전 게임 화면처럼 "지금 할 것 하나"만 크게.
- **색 5개**: 먹 `#0e0e11`(바탕) · 숯 `#1b1b20`(사선 띠) · 분필 `#f2f0ea`(글자) · 신호 빨강 `#ff4655`(가장 큰 버튼 · 고른 탭, 한 화면 한 곳) · 볼트 노랑 `#f5e663`(정답 · 콤보 · 연속 숫자만).
- **글꼴**: 제목 · 숫자 · 버튼 = 검은고딕(Black Han Sans, 1굵기), 본문 = Pretendard 500/700/800.
- **버튼**: 둥근 모서리 0, 평행사변형(−12°), 글자는 반대로 세움. 누르면 2px 밀리고 80ms 흰빛.
- **뼈대**: 홈 = 펫이 오른쪽 위에서 화면 밖으로 넘침 + 이름 큰 글자 + 숫자 두 개 + 빨강 버튼 하나 + 번호 붙은 메뉴 줄(02 야차전 · 03 놀이터 · 04 도감). 공부 = 20칸 막대 + 큰 단어 + 기울어진 보기 4줄, 정답은 노랑 채움 + "정답" 도장 + 조각 4개 + 펫이 아래에서 튀어나옴. 야차전 = 사선으로 나눈 "나 vs 상대" 판 + 기술 버튼처럼 쌓은 설정 줄(포켓몬 챔피언스 원칙).
- **움직임**: 140~260ms, 미끄러져 들어와 멈춤, 도장 · 콤보는 커졌다 줄어듦. transform · opacity만.
- **말투**: 짧은 명사형, 숫자 먼저("20개 ▶", "3명 도전 대기", "6연속!"). 느낌표는 펫 말풍선에만.

### 02(B) · 코발트 포커스 — `b-cobalt.html`
- **한 줄**: 홈 위쪽을 진한 파랑으로 채우고 흰 큰 글자 한 문장으로 오늘 할 일을 말함. 공부 화면은 흰 바탕에 문제만.
- **색 5개**: 코발트 `#2f45ff` · 밤 `#0d1240`(글자 · 야차전 바탕) · 흰 `#ffffff` · 얼음 `#e4e8ff`(연한 면 · 단어 강조) · 레몬 `#ffe14d`(연속 · 보상 숫자만).
- **글꼴**: Pretendard 가변 하나(제목 900, 자간 −4.5% / 본문 500~800). 글꼴 파일이 하나라 가장 가벼움.
- **버튼**: 알약 60px 하나. 파랑 위에서는 흰 버튼, 흰 위에서는 파랑 버튼. 누르면 97%.
- **뼈대**: 홈 = 파랑 면(문장 + 연속 + 시작 버튼) 위에 펫이 걸쳐 앉고 흰 판이 아래에서 올라옴, 판에는 숫자 · 요일 막대 · 줄 2개. 공부 = 얇은 진행 막대 + 큰 단어 + 줄 보기, 정답 줄이 왼쪽부터 파랑으로 채워짐 + 동그란 펫 얼굴 + "6개 연속 정답". 야차전 = 밤색 바탕, 내 펫 vs 점선 동그라미 "?", 숫자 3개 줄, 알약 선택.
- **움직임**: SEED 디자인 값 그대로(들어옴 `cubic-bezier(0,0,.15,1)`, 강조 `(.03,.4,.1,1)`, 작은 반응 200ms 이하).
- **말투**: 해요체 한 문장("오늘 20단어면 청룡이 진화해요", "친구 3명이 기다려요").

### 03(C) · 홀로 도감 — `c-archive.html`
- **한 줄**: 펫과 공부한 단어를 "수집 카드"로. 진주빛 바탕 + 먹색 테두리, 홀로 빛은 펫 · 보상에만, 각진 세리프 제목.
- **색 5개 + 홀로**: 진주 `#eeedf3` · 먹보라 `#1c1a27`(글자 · 테두리 · 주 버튼) · 종이 `#fbfaf7`(카드 안쪽) · 금 `#b8892a`(등급 · 번호) · 체리 `#d9434b`(도장 · 오답) + 홀로 그라데이션(`#a6f0e2 → #c9b8ff → #ffc9de → #fff0b3`).
- **글꼴**: 제목 · 숫자 · 영어 단어 = 함렛(Hahmlet) 600/700/800, 본문 = Pretendard.
- **버튼**: 먹색 네모(둥근 14) 58px. 고른 것은 홀로 테두리 + 작은 마름모.
- **뼈대**: 홈 = 파트너 카드가 기울어져 앞에, 다른 펫 카드 2장이 부채처럼 뒤에 + 진화까지 남은 경험치 도장 + 도감 칸 24개(채운 칸은 펫 얼굴). 공부 = 단어가 카드 한 장(No.128 / 268), 정답이면 카드가 뒤집히며 뜻이 보이고 빛 한 줄 + "수집" 도장, 아래에 펫 경험치 막대. 야차전 = 내 카드 vs 뒤집힌 상대 카드 + 규칙 카드 줄.
- **움직임**: 카드 펼침 520ms, 뒤집힘 520ms, 빛 한 줄 1회(transform). 계속 반짝이지 않음.

| 갈무리11 Galmuri11 (이민서) | SIL OFL 1.1 — npm `galmuri` 2.40.3 `ofl.md` | 도트라 작음(시안 서브셋 12KB) | `fonts/galmuri11-*.woff2` |

- 한글 2,350자 크기 중 "약"으로 적은 것은 원본 크기 비율로 어림한 값입니다(검은고딕 · 함렛 · Pretendard만 실제로 서브셋을 만들어 쟀습니다).
- **IBM Plex Sans KR은 뺐습니다**: 라이선스에 "Reserved Font Name Plex"가 있어 서브셋(고친 판)을 만들면 이름을 바꿔야 합니다.

- OFL은 상업 이용 · 앱에 넣기 · 서브셋 모두 됩니다(이름 "Reserved Font Name"이 있는 글꼴은 고친 파일 이름을 바꿔야 함 — 셋 다 해당 없음).
- 시안 폴더의 글꼴은 **시안에 나온 글자만** 남긴 것입니다. 실제 앱에 넣을 때는 2,350자 서브셋을 다시 만들고, `font-display: swap`으로 글꼴이 늦게 와도 글자는 바로 보이게 합니다.
- 무게 비교: A = 검은고딕 167KB(+ 본문은 기기 글꼴 그대로도 가능), B = Pretendard 하나 170~432KB, C = 함렛 177KB + Pretendard. **A가 제일 가볍습니다**(제목 글꼴 하나만 더 싣고 본문은 지금처럼 기기 글꼴).

## 7. 추천

**10방향 중 2~3개: 01 스트릿 HUD(1순위) · 04 매거진 커버 · 03 홀로 도감**
- **01 스트릿 HUD**: 아래 이유. 학생들이 매일 보는 게임 · 디스코드와 같은 어두운 화면, 연출을 가장 크게 살리고 글꼴도 가장 가벼움.
- **04 매거진 커버**: 10개 중 가장 "요즘"이고 스토리에 올리고 싶은 화면. 밝은 쪽을 원하시면 01 대신 이것. 다만 공부 화면까지 표지 문법을 끌고 가기 어려워, 공부 화면은 02처럼 흰 바탕으로 갈라야 합니다.
- **03 홀로 도감**: 토스 글에서 본 "직접 키워야 매일 온다"와 가장 잘 맞음(공부 = 카드 모으기). 펫을 좋아하는 학생에게 강함.
- 덜 권하는 것: 05 월광 RPG(멋있지만 글꼴이 무겁고 어두운 금색은 정보가 많은 화면에서 읽기 어려움), 08 픽셀(재밌지만 오래 쓰면 피곤), 09 리그(순위 부담), 10 다꾸(여학생 쪽으로 치우침), 07 팝 스티커(중학생 느낌이 날 수 있음), 06 플래너(공부 앱 같아 "놀러 오는" 느낌이 약함), 02 코발트(가장 안전하지만 다른 학습 앱과 비슷함).

### 1순위 01 · 스트릿 HUD를 미는 이유

**이유**
1. **목표("고등학생이 멋있다고 느끼고 더 자주 찾음")에 가장 가깝습니다.** 학생들이 매일 쓰는 디스코드 · 로블록스 · 대전 게임과 같은 어두운 화면이라 "공부 앱"보다 "내 게임"처럼 보입니다. B는 깔끔하지만 다른 학습 앱과 비슷해지고, C는 펫을 좋아하는 학생에게 강하지만 남학생에게는 부드러워 보일 수 있습니다.
2. **우리 앱의 강점(야차전 · 놀이터 · 펫 진화 연출)을 살립니다.** 검정 바탕에서 펫 그림(파스텔 · 금빛)이 가장 잘 뜨고, "퀄리티 높게" 연출(정답 도장, 콤보, 사선 VS)이 같은 문법으로 이어집니다. 연출을 줄이지 않습니다.
3. **가볍습니다.** 글꼴 하나(167KB, 한 번만 받음), 그림자 · 흐림 · 큰 그림 없음, 움직임은 transform · opacity만. 렉 방지 규칙 8번과 맞습니다.
4. **바꾸는 기준이 단순합니다**: 색 5개, 기울기 하나(−12°), 둥근 모서리 0. 화면마다 따로 고민할 것이 적어 "또 AI 같은" 화면이 다시 생기기 어렵습니다.

**A의 약점과 대비**
- 어두운 바탕에서 긴 글 읽기: 공부 화면의 예문 · 해설은 분필색 16px 이상, 회색 글자는 대비 4.5:1 이상(`#8d8d96` on `#0e0e11` 약 5.9:1, 계산값)만 씁니다.
- 학교에서 밝은 화면을 원하는 학생: 공부 화면만 B처럼 밝게 하는 "밝은 공부 화면" 옵션을 2단계에서 검토할 수 있습니다.

### 실제 앱에 넣을 때 바뀌는 범위와 순서 (각 단계 = PR 하나, 새 세션)

| 순서 | 무엇 | 범위 | 렉 방지 |
|---|---|---|---|
| 1 | 토큰 · 글꼴 · 탭 바 · 머리줄 | 새 CSS 한 파일(색 5개 · 기울기 · 움직임 변수) + 검은고딕 서브셋(`public/assets/fonts`) + 탭 바 · 머리줄. 영어 꼬리표 제거 | 글꼴은 서비스 워커 미리 받기에 넣고 swap. 서버 변경 없음 |
| 2 | 홈 | 펫 크게 + 숫자 2개 + 빨강 버튼 하나 + 번호 메뉴 줄. 쓰다듬기 · 밥 주기 · 칭호 · 알 상점은 "나"나 펫 화면으로 옮김(선생님 확인) | 홈 GET 응답은 그대로, 화면만 |
| 3 | 단어 공부 · 연습 결과 | 20칸 막대, 기울어진 보기, 정답 도장 · 콤보 · 펫 반응 | 답마다 바뀐 줄만 다시 그림(8번 규칙) |
| 4 | 야차전 대결 준비 · 대결 | 사선 VS 판, 기술 버튼식 설정 줄 | `node docs/yacha-perf.mjs`로 폰 390px · CPU 4×·6× 확인 |
| 5 | 놀이터 · 상점 · 도감 · 나 | 같은 문법으로 차례로 | 게임 안쪽 화면(아레나 · 러너)은 손대지 않음 |
| 6 | 지난 CSS 정리 | `public/v13xxx.css` 여러 겹을 새 토큰으로 합침 | 첫 화면 CSS 크기 줄어듦 |

각 단계는 `npm run check` · `check:cloudflare` 통과, PR에 "렉 방지 점검" 칸, 바뀐 규칙은 `server/*-check.mjs`에 검사를 남깁니다(예: 영어 꼬리표 0개, 색 변수 밖의 색 금지).

## 8. 선생님이 정할 것

1. **깊게 볼 2~3방향 고르기**(1~10 중). 추천은 01 · 04 · 03. 섞기도 됩니다(예: "01의 홈 · 야차전 + 02의 밝은 공부 화면").
2. **어두운 화면을 기본으로 해도 되는지**(A). 교실 프로젝터 · 선생님 화면은 지금처럼 밝게 둡니다.
3. **홈에서 빠지는 것의 자리**: 쓰다듬기 · 밥 주기, 오늘 돌본 펫, 내 펫 22/94, 칭호 11/172, 알 상점 — "나" 탭으로 옮길지, 펫을 누르면 나오게 할지.
4. **글꼴 싣기**: 검은고딕 167KB를 첫 방문에 한 번 받는 것 괜찮은지(본문은 지금처럼 기기 글꼴).
5. **탭 이름 · 순서**: 홈 · 학습 · 야차전 · 놀이터 · 나 그대로 두는 것으로 시안을 만들었습니다. 바꿀지.
6. **시안 속 문구**("20개 ▶", "3명 도전 대기", "6연속!")처럼 짧은 반말 · 명사형 말투로 가도 되는지.
7. 시안의 숫자 · 펫 이름(구미호 루나 등) · "진화까지 이틀" 같은 문장은 예시입니다. 실제 규칙이 아니며 **새 재화 · 새 보상은 만들지 않습니다.**
