# 인형뽑기 구성안 (놀이터 새 게임)

> 그림 주문서는 **42 · 43 · 44 · 45**(`docs/asset-requests/runner/build-42.mjs`가 만든다). **V13.180에서 구현했다**(선생님: "추천안으로 가자"): 규칙 `public/modules/claw-rules.js`, 서버 `server/claw.mjs`, 화면 `public/modules/claw.js` · `public/v13180.css`, 검사 `server/claw-check.mjs`. 소리는 기존 효과음으로 먼저 연결했다(전용 합성음은 §10의 다음 작업).

선생님이 보여 준 두 게임(민트 등각 "ZOO PARTY" 인형뽑기, 분홍 3D 토이크레인)의 좋은 점을 합친다.

| 가져오는 것 | 출처 | 우리 앱에서 |
|---|---|---|
| 집게 위치 · 상태 · 그립 세기 숫자판(READOUT), 도전 기록 | ZOO PARTY | 기계 아래 숫자판에 `X · Y · 상태 · 그립`을 앱이 글자로 쓴다(그림에는 글자 없음) |
| 키보드 조작(DROP 스페이스) | ZOO PARTY | 방향키/WASD 이동, 스페이스 · 엔터 DROP |
| 한 판 = 시간 + 인형 수, 위쪽에 "뽑은 · 남은 · 도감 · TIME" | 토이크레인 | 위쪽 띠: 뽑은 인형 · 남은 집게 · 도감 n/12 · 남은 시간 |
| 폰용 큰 조이스틱(왼쪽 아래) + DROP(오른쪽 아래) | 토이크레인 | 그대로(폰 우선) |
| 배출구(아래 왼쪽 구멍)로 굴러 떨어짐 | 토이크레인 | 앞 왼쪽 아크릴 배출구 + 아래 상품 문이 열리며 인형이 튀어나옴 |
| 카메라 버튼(왼쪽 · 앞 · 오른쪽 · 확대) | 토이크레인 | 3D가 아니라서 **확대 보기 버튼 하나** + 내릴 때 자동 확대 · 살짝 기울기(층 그림 시차)로 대신한다 |
| 선물 사진으로 내 머신 만들기 · 링크 공유, 코인 넣기 | ZOO PARTY | **넣지 않는다**(코인 대신 공부로 받은 집게권) |

## 1. 화면 흐름

```
놀이터 '게임' 묶음                       기계 화면                                  결과 · 도감
┌─────────────┐  들어가기   ┌───────────────────────────────┐  판 끝   ┌───────────────────┐
│ 🧸 인형뽑기   │ ─────────▶ │ 위 띠: 뽑은 · 남은 집게 · 도감 · TIME │ ──────▶ │ 이번 판 인형(기쁨 자세)│
│ 집게권 n · 도감 │            │ 기계(유리 속 인형 20개, 집게)       │          │ +코인 · 새 인형 NEW   │
│ n/12 · 들어가기│            │ 숫자판 X · Y · 상태 · 그립         │          │ [한 판 더] [도감]     │
└─────────────┘            │ 조이스틱 ◉        [ DROP ]        │          └───────────────────┘
                            └───────────────────────────────┘                  │
                                    ▲ 집게권 넣기(시작)                          ▼
                                    └──────────── 도감(12칸 + 황금 12칸, 칭호 안내)
```

1. **놀이터 카드**: `public/modules/arcade-games.js`의 `gamesSection`에 `clawCard(A, art)`를 낚시터 · 짝 맞추기 · 몬스터 사냥과 같은 `ag-big` 그림 카드로 넣는다. 그림은 `claw/entry`가 있으면 쓰고, 없으면 코드 그림. 통계 3칸: 집게권 · 도감 n/12 · 오늘 코인 n/30.
2. **기계 화면**: 몬스터 사냥(`hunt.js`) · 낚시(`reel.js`)처럼 전체 화면 시트. 들어가면 대기 상태(기계 불빛만 반짝, 인형 더미가 숨 쉬듯 살짝 흔들림) → **[집게권 넣기]** 를 누르면 판 시작(서버 `/claw/start`) → 30초 조준 · 집게 3번 → 판 끝.
3. **결과**: 이번 판에 뽑은 인형을 기쁨 자세로 줄 세우고 코인 · NEW · 도감 진행을 보여 준다. 꽝이면 "아깝다! 다음 집게는 조금 더 잘 잡혀요"(연속 실패 보정 안내).
4. **도감**: 12칸(못 뽑은 칸은 기본 그림으로 만든 실루엣) + 황금 12칸. 칸을 누르면 인형이 기쁨 자세로 통통 튀고, 몇 번 뽑았는지 · 처음 뽑은 날을 보여 준다. 위쪽에 칭호 진행.

## 2. 한 판 규칙

| 항목 | 값(추천) | 메모 |
|---|---|---|
| 한 판 비용 | 집게권 1장 | 코인을 쓰지 않는다 |
| 조준 시간 | **30초**(판 전체) | 집게가 내려가 · 올라와 · 배출구로 가는 연출(약 4.5초) 동안은 멈춘다. 0초가 되면 그 자리에서 자동 DROP |
| 인형 수 | **20개** | 서버가 판 id로 배치를 정한다(그림이 있는 인형만, §8) |
| 집게 수 | **3번**(추천) | 1번은 너무 짧고(0.3개), 3번이면 판마다 약 0.86개(열심) · 0.67개(보통). 집게를 다 쓰거나 시간이 끝나면 판 끝 |
| 조준 판정 | 집게 중심과 맨 위 인형 중심 거리 ÷ 인형 반지름 | `perfect` ≤ 0.35 · `good` ≤ 0.7 · `edge` ≤ 1.0 · 그보다 멀면 `miss`(아무것도 안 닿음) |
| 잡힐 확률 | perfect **38%** · good **26%** · edge **10%** · miss 0% | 인형마다 다르지 않다(공평) |
| 황금 인형 | 판마다 **25%** 확률로 1개, 더미 위쪽 | 잡힐 확률 ×**0.5** |
| 연속 실패 보정 | 닿았는데 놓칠 때마다 다음 집게 **+5%p**, 최대 **+20%p** (edge는 절반) | 뽑으면 0으로. 판이 바뀌어도 이어진다(`p.claw.m`) |
| 대박(두 개) | 뽑을 때 **4%** 확률로 바로 옆 인형이 같이 딸려 나온다 | 연출이 크다(§9). 하루 코인 상한 안에서만 코인 |
| 놓침 모양 | 서버가 고른다: 올라가다 미끄러짐 60% · 배출구 바로 앞에서 떨어짐 15% · 쥐다 빠짐 25% | 연출만 다르고 결과는 같다(꽝) |

**밸런스(시뮬레이션, 구현 세션이 `clawSim`으로 검사에 넣는다)**: 조준 비율 열심(perfect 40 · good 35 · edge 15 · miss 10%) · 보통(20 · 35 · 25 · 20%)으로 30일 2,000번 돌린 값.

| 학생 | 하루 판 | 판당 인형 | 30일 인형 | 도감 12종 완성 | 황금(30일) |
|---|---:|---:|---:|---|---:|
| 열심 | 3 | 0.86 | 약 78 | 약 2주(30일 안 97%) | 약 10 |
| 보통 | 1 | 0.67 | 약 20 | 약 8주(90일 안 87%) | 약 2.6 |

## 3. 서버 판정 (몬스터 사냥과 같은 방식)

`server/hunt.mjs`의 `huntThrow`(서버 난수 `secureRandom`, 영수증 `findReceipt` · `keepReceipt`, `guardQuality`)를 그대로 본뜬다. 규칙 숫자는 `public/modules/claw-rules.js`(서버 · 화면이 같이 읽음), 서버 쪽은 `server/claw.mjs`, 화면은 `public/modules/claw.js`.

### 서버가 정하는 것 / 화면이 그리는 것

| 서버가 정한다 | 화면(클라이언트)이 그린다 |
|---|---|
| 판 id, 인형 20개 배치(종류 · 황금 · 위치 · 층 · 기울기 · 크기): `seeded(판 id)` | 배치대로 인형을 깊이 순서로 그리기, 숨 쉬는 흔들림 |
| 조준 판정(perfect · good · edge · miss): 받은 x · y와 서버가 아는 배치로 | 조이스틱 · 키보드로 집게 움직이기, 숫자판 X · Y |
| 잡힘 · 놓침 · 대박, 놓침 모양, 그립 세기 숫자(연출용) | 내림 · 쥠 · 들어 올림 · 미끄러짐 · 배출구 연출 |
| 남은 집게, 판 끝, 코인, 도감, 칭호 진행 | 결과 · 도감 화면, 소리 · 진동 |
| 흔들림(뽑힌 인형 위 인형이 내려앉는 방향 `nudge`) | 그 방향으로 짧게 미끄러지는 연출 |

### 요청 · 응답 모양

```
POST /api/claw/home   {}                                  → { claw: 보기 }
POST /api/claw/start  { id: '판번호(화면이 만듦 8~40자)' }    → { round: { id, dolls: [{ i, k, g, x, y, z, r, s }], drops: 3, time: 30 }, claw: 보기 }
POST /api/claw/drop   { id: '집게번호', round, n, x, y, ms } → { n, aim, target, result, slip, grip, doll: { k, g } | null, extra: { k, g } | null,
                                                             fresh, coins, nudge: [{ i, dx, dy }], left, end, summary?, claw: 보기 }
```

- `dolls[]`: `i` 0~19, `k` 인형 key, `g` 황금이면 1, `x` · `y` 0~1(기계 바닥 위치, y가 클수록 앞), `z` 0~2(층: 0 바닥 · 2 맨 위), `r` 기울기(-20~20도), `s` 크기(0.9~1.1).
- `n`: 이번 집게 번호(0 · 1 · 2). `ms`: 판 시작부터 지난 시간(참고용, 판정은 서버 시각).
- `aim`: `perfect` · `good` · `edge` · `miss`. `target`: 닿은 인형 `i`(miss면 null). `result`: `win` · `slip` · `miss`. `slip`: 놓침 모양(`lift` · `chute` · `loose`). `grip`: 숫자판에 보일 그립 세기 0~99(연출용).
- `summary`(판 끝일 때만): `{ won: [{ k, g }], coins, book: n }`.
- `claw` 보기: `{ tickets, max, got{ practice, attend, match }, book[12], gold[12], coin_today, coin_daily, live: 판이 열려 있으면 { id, n, left, ends } }`.

### 부정 방지

| 규칙 | 값 | 어기면 |
|---|---|---|
| 집게권은 서버가 공부 끝에만 준다 | 연습 10문제 이상 · 출석 · 짝 맞추기 별 3, 곳마다 하루 1장 | 화면이 보낼 방법이 없다 |
| 판 시작은 영수증으로 한 번 | 같은 `id`를 다시 보내면 같은 판(집게권 다시 안 씀) | — |
| 판은 하나만 열린다 | 열린 판이 있으면 그 판을 돌려준다 | 끝난(시간 지난) 판은 닫고 새 판 |
| 집게 번호는 차례대로 한 번 | `n`이 다음 번호와 다르면 거절, 같은 집게 `id`면 저장한 결과 | 400 / 영수증 결과 |
| 최소 시간 | 첫 집게는 시작 뒤 **1.2초**, 다음 집게는 앞 집게 뒤 **4.0초**(연출 길이) | 그보다 빠르면 조준 없음(`miss`) 처리 |
| 판 마감 | 시작 + 30초 + 집게 연출 3 × 4.5초 + 여유 15초(시간이 끝난 뒤 남은 집게는 5초씩) | 마감 뒤 집게는 거절, 판 닫힘 |
| 조준 비율 상한 | 최근 20번(8번 전에는 보지 않음) 중 perfect가 **70%** 이상이면 이번 perfect → good, perfect+good가 **95%** 이상이면 → edge(구현 때 60 · 90에서 바꿈: 잘하는 학생이 11% 깎여서) | `QUALITY_GUARD`와 같은 생각: 좌표를 꾸며 늘 한가운데를 보내도 이득이 막힌다 |
| x · y 범위 | 0~1로 자르고 소수 셋째 자리까지 | — |
| 하루 코인 상한 | **30코인** | 넘으면 인형 · 도감은 그대로, 코인만 0 |
| 미리보기(교사) 계정 | 들어올 때 집게권 6장 채움, 활동 기록 안 남김 | 몬스터 사냥 `PREVIEW`와 같다 |

## 4. 집게권 규칙

### 몬스터 사냥 공을 같이 쓸까, 새 자원을 둘까

| | A. 공 같이 쓰기 | **B. 새 자원 "집게권"(추천)** |
|---|---|---|
| 공부 동기 | 그대로 | 같은 공부 활동이 두 게임을 같이 채워서 조금 더 커짐 |
| 경제 | 늘지 않음 | 늘어남 → 인형뽑기 하루 가치를 사냥의 약 ¼로 작게 잡아 막는다(§6) |
| 학생이 느끼기 | "공을 사냥에 쓸까 인형뽑기에 쓸까" 고민, 사냥 밸런스(`huntSim` · 하루 가치 검사)가 같이 흔들림 | 두 게임이 따로 굴러감, 놀이터 카드에 각자 개수 |
| 구현 | 사냥 검사 · 화면 · 공 문구를 같이 고쳐야 함 | `grantBall` 옆에 `grantClaw` 한 줄씩(같은 세 곳) |

→ **B 추천**: 사냥 밸런스를 건드리지 않고, 인형뽑기 가치는 작게 둔다.

| 항목 | 값(추천) |
|---|---|
| 받는 곳 | `practice`(연습 끝내기 10문제 이상) · `attend`(출석) · `match`(짝 맞추기 별 3) — `HUNT.SOURCES`와 같은 세 곳, 곳마다 하루 1장 |
| 하루 최대 | **3장** |
| 보관 상한 | **6장**(꽉 차면 그날은 안 받음, 받는 곳 표시는 "가득") |
| 이월 | 된다(상한 6장까지). 이틀 쉬어도 6장까지 모아 둘 수 있다 |
| 보너스 | 없음(출석 도장판 · 만점 보너스는 사냥 공에만). 단순하게 둔다 |
| 연결 자리 | `server/service.mjs`의 `grantBall(student, 'practice', …)` · `grantBall(p, 'attend', …)`, `server/games.mjs`의 `grantBall(p, 'match', …)` 바로 옆 |

### 칭호(`public/modules/titles.js`, 묶음 `arcade` 놀이터)

| key | 이름 | 등급(코인) | stat · goal | 얻는 법 |
|---|---|---|---|---|
| `claw1` | 첫 인형 | 일반(10) | `claw_dolls` · 1 | 인형 1개 뽑기 |
| `claw6` | 인형 수집가 | 희귀(30) | `claw_kinds` · 6 | 도감 6종 |
| `claw12` | 인형뽑기 장인 | 영웅(60) | `claw_kinds` · 12 | 도감 12종 완성 |
| `clawgold` | 황금 손 | 희귀(30) | `claw_gold` · 1 | 황금 인형 1개 |
| `claw100` | 집게의 전설 | 전설(120) | `claw_dolls` · 100 | 인형 100개 뽑기 |

- 새 title stat 3개(`claw_dolls` · `claw_kinds` · `claw_gold`)는 `server/competition.mjs`의 `titleStats`가 `p.claw`에서 센다. `titles.js` 맨 위 stat 설명 주석에 한 줄씩 더한다.
- 칭호 메달 그림은 이번 주문에 넣지 않았다(기존 칭호도 그림 없이 `icon`으로 먼저 나온다). 원하면 다음에 칭호 3탄 주문서로.
- **희귀 인형 제안**: 황금 인형(추천, 위 표)만 먼저 둔다. 그림을 따로 그리지 않고 기본 그림에 금빛 필터 + `claw/gold-aura` · `claw/gold-ribbon`(주문서 45)을 겹친다. 이벤트 인형(예: 할로윈 호박 · 크리스마스)은 계절마다 1종씩 나중에 주문서로 더하고, 도감 13칸째 "이벤트" 줄로 따로 센다(12종 완성 칭호에는 넣지 않는다).

## 6. 하루 가치 표

계산: 받은 코인 + 칭호 코인 + 도감 완성 보너스를 날 수로 나눔. 30일 기준(처음 한 달, 칭호가 몰리는 때).

| 학생 | 하루 집게권 | 인형 코인/일 | 칭호 · 보너스/일 | **하루 가치** | 90일 평균 |
|---|---:|---:|---:|---:|---:|
| 열심 | 3장(3판) | 약 18.6 | 약 7.5 | **약 26코인** | 약 23 |
| 보통 | 1장(1판) | 약 5.2 | 약 2.4 | **약 8코인** | 약 8 |

근거:
- 낚시 · 몬스터 사냥의 하루 가치는 각각 "열심 약 90 · 보통 약 30코인어치"다(`hunt-rules.js` 맨 위 주석, `hunt-check.mjs`의 `dayValue` 75~105 · 24~40 검사). 집게권도 같은 공부 활동에서 따로 나오므로, 같은 크기로 두면 놀이터 하루 가치가 1.5배가 된다.
- 그래서 인형뽑기는 **사냥 · 낚시의 약 ¼**(열심 약 25 · 보통 약 8)로 잡았다. 펫 · 알이 나오지 않고 인형(도감)이 보상의 중심이라 코인은 "덤"이다.
- 다른 하루 한도와 견주기: 공부 코인 상한 150(`STUDY_COINS.cap`), 사냥 별조각 → 코인 하루 60, 낚시 진주 → 코인 하루 100. 인형뽑기 하루 30은 그보다 작다.
- 구현 세션 검사: `clawSim`(위 조건, 3,000번)의 30일 하루 가치가 열심 **20~32** · 보통 **5~11** 안에 있어야 한다.

## 8. 그림이 오기 전에도 앱이 깨지지 않게 (그림 게이트)

몬스터 사냥 `monsterReady`(`MONSTER_ART`) · 펫 `petReady`(`PET_ART`)와 같은 방식이다.

1. `server/build-assets.mjs`에 블록 하나: `public/assets/claw/`를 보고 `public/modules/claw-art.js`를 만든다.
   - `CLAW_DOLLS`: `doll-<key>` · `-grab` · `-fall` · `-joy` 네 장이 다 있는 인형 key.
   - `CLAW_ART`: 그 밖에 있는 그림 이름(기계 · 집게 · UI · 배경 · 도감 · 효과).
   - `CLAW_OPEN`: `machine` · `claw-open` · `claw-closed` · `claw-grip-back` · `claw-grip-front`가 있고 `CLAW_DOLLS`가 **6종 이상**이면 true.
2. `dollReady(k) = CLAW_DOLLS.has(k)`. 서버 배치는 그림이 있는 인형만 고른다. 도감 칸 수 · `claw12` 목표는 12 그대로(그림이 다 와야 완성할 수 있다).
3. `CLAW_OPEN`이 false면 놀이터 카드는 "곧 열려요" 회색 카드, `/claw/start`는 409. 집게권은 그래도 쌓인다(상한 6).
4. UI · 배경 · 효과 그림은 `CLAW_ART.has(name)`일 때만 쓰고, 없으면 코드 그림(CSS 그라디언트 · 이모지)으로 그린다(`HUNT_ART` · `FISHING_ART`와 같다).
5. 검사: 빈 목록을 넘겨 그림이 없을 때 모습도 본다(`arcade-games.js`가 이미 그렇게 한다).

## 9. 연출 목록 (퀄리티 업 · 줄이지 않는다)

**그리는 방식**: 3D 라이브러리를 쓰지 않는다(`index.html` CSP가 외부 스크립트를 막고 모든 코드가 정적 파일). 스프라이트 층 + CSS transform/Canvas 2D로 2.5D를 만든다.

층(뒤 → 앞): 배경(`bg-*`) → 기계 본체(`machine`, 속 뒷벽 · 바닥 포함) → 인형 더미(y · z 순서로 정렬) → 집게 뒤 발톱(`claw-grip-back`) → 잡힌 인형 → 집게 앞 발톱(`claw-grip-front`) · 줄 · 레일(`rail-x` · `rail-y` · `carriage`) → 배출구 앞벽(`chute-front`) → 유리 반사(`glass-glare`) → UI.

### 인형 더미: 가벼운 물리 vs 미리 그린 겹침 배치

| | 가벼운 물리(원 충돌) | **틀 배치 + 짧은 연출(추천)** |
|---|---|---|
| 서버와 맞음 | 화면이 인형을 움직이면 서버가 정한 "닿은 인형"과 어긋날 수 있다 | 서버가 판 id로 정한 자리 그대로 → 늘 맞다 |
| 구현 | 충돌 · 쌓임 · 떨림 튜닝, 폰 성능 | 더미 모양 틀 4개(20자리, x · y · z) + 종류 · 기울기만 섞기 |
| 보기 | 잘 되면 자연스럽지만 떨림 · 겹침 버그가 보이기 쉽다 | 미리 다듬은 겹침이라 늘 예쁘다. 뽑힌 자리 위 인형은 `nudge` 방향으로 0.3초 내려앉는다 |

→ **틀 배치 추천.** 숨 쉬는 흔들림(인형마다 다른 위상의 ±1.5도 · 1px), 집게가 닿을 때 주변 인형 출렁임은 CSS 애니메이션으로.

### 연출 전체

| 순간 | 연출 |
|---|---|
| 대기 | 기계 위 전구 줄 순서대로 깜빡(`fx-sparkle`), 유리 반사가 천천히 지나감, 배경 반짝이 떠다님, 인형 숨쉬기 |
| 집게권 넣기 | 집게권 아이콘이 기계 투입구로 쏙 → 기계 불빛 한 바퀴 → 위 띠 TIME 30이 탁 켜짐 |
| 조준 | 집게가 조이스틱을 따라 가속 · 감속(관성), 레일 · 받침이 같이 움직임, **바닥에 집게 그림자**(높이만큼 작고 진하게) + 그림자 아래 인형 테두리가 살짝 밝아짐(조준 도움), 숫자판 X · Y가 바뀜, 남은 5초부터 TIME 빨갛게 째깍 |
| 깊이감 | y가 클수록(앞) 인형 · 그림자 크게, 집게가 앞쪽이면 크게. 기계 전체가 집게 x를 따라 ±3도 기울고 층마다 다른 거리로 밀림(시차) |
| 확대 보기 | 버튼 하나: 집게 주변을 1.6배로 부드럽게 확대(조준 중에도). 내릴 때는 자동으로 1.3배 따라 확대 |

| 쥠 | 발톱이 닫히며 인형을 감쌈(뒤 발톱 → 인형 → 앞 발톱 층), 인형이 `grab` 자세로 바뀌고 살짝 눌림, 숫자판 GRIP 숫자가 올라감 |
| 들어 올림 | 인형이 흔들리며 올라감(진자), 잘 잡혔으면 안정, 놓칠 판이면 점점 크게 흔들림 |

| 성공 | 배출구 위에서 발톱 열림 → 인형이 `fall` 자세로 회전하며 떨어짐 → 아크릴 배출구 안에서 통통 → 아래 상품 문(`prize-door`)이 열리며 인형이 `joy` 자세로 튀어나옴 + 별 · 리본 색종이 |
| 대박(두 개) | 화면 금빛 섬광(`fx-jackpot`), 두 인형이 차례로 떨어짐, 기계 전구 전체 빠르게 깜빡, 큰 진동 |
| 황금 인형 | 더미 속에서 금빛 오라(`gold-aura`)가 천천히 빛남, 뽑으면 금빛 빛줄기 + 황금 리본 배지 |
| NEW · 도감 | 처음 뽑은 인형은 결과에서 카드(`card`)가 뒤집히며 등장 + NEW 리본, 도감 칸으로 날아가 꽂힘 |

`prefers-reduced-motion`이면 흔들림 · 시차 · 화면 흔들림만 줄이고 결과 연출은 그대로 둔다.

## 12. 검사 목록 (구현 세션이 `server/claw-check.mjs`에 넣고 `release-check.mjs`에서 부른다)

1. 규칙 숫자: 30초 · 20개 · 집게 3 · 확률(38 · 26 · 10) · 보정(+5, 최대 20) · 황금(25%, ×0.5) · 대박 4% · 코인(6 · 20 · 하루 30) · 집게권(곳 3 · 상한 6).
2. 배치: 같은 판 id → 같은 배치, 다른 id → 다른 배치, 20개 · 그림 있는 인형만 · 황금 0~1개.
3. 판정: 좌표 → aim 경계값(0.35 · 0.7 · 1.0), 맨 위(z) 인형이 먼저 닿음, 뽑힌 인형은 다음 집게에 없음.
4. 영수증: 같은 판 id · 같은 집게 id를 다시 보내도 집게권 · 집게를 또 쓰지 않는다.
5. 부정: 집게 번호 건너뛰기 · 같은 번호 두 번 · 1.2초 / 4.0초보다 빠른 집게 · 마감 뒤 집게 · 열린 판 없이 집게 → 거절 또는 miss.
6. 조준 상한: 늘 한가운데를 보내는 스크립트는 perfect가 60% 이하로 깎인다. 보통 · 잘하는 학생(perfect 20% · 40%)은 거의 걸리지 않는다(5% 미만).
7. 연속 실패 보정: 놓칠수록 오르고, 뽑으면 0, 판이 바뀌어도 이어짐.
8. 하루 코인 30 상한, 도감은 상한 뒤에도 늘어남, 다음 날 다시 받음.
9. 집게권: 곳마다 하루 1장, 상한 6, 이월, 모르는 곳은 null, 세 연결 자리 문자열 검사.
10. 밸런스: `clawSim` 30일 하루 가치 열심 20~32 · 보통 5~11.
11. 칭호: `claw1` · `claw6` · `claw12` · `clawgold` · `claw100`이 stat으로 열리고 `rewardIncome`에 `p.claw.coins`가 들어감.
12. 그림 게이트: 빈 그림 목록이면 카드가 "곧 열려요", `/claw/start` 409, 화면이 깨지지 않음. `build:assets`가 `claw-art.js`를 만든다.
13. 활동 기록: 판 끝에 한 줄, 다시 보내면 안 늘어남, 미리보기 계정은 안 남김.
14. 저장 크기: `p.claw` 영수증 빼고 600바이트 이하, `publicProfile`에 배치 · 영수증 없음.
15. 펫 경제: 인형뽑기에서 `p.pets` · 알이 절대 늘지 않는다.
16. 소리: 새 key가 `SOUND_GAIN`에 있고 파일이 있다(`sound-check.mjs`).

1. **이름**: 게임 이름 "인형뽑기"(추천) · 인형 이름 12개(추천: 쪼꼬 쥐 · 음메 소 · 어흥 호랑이 · 깡총 토끼 · 미르 용 · 스르르 뱀 · 따각 말 · 몽실 양 · 끼끼 원숭이 · 꼬꼬 닭 · 멍멍 강아지 · 꿀꿀 돼지).
2. **한 판 집게 수**: 3번(추천) / 2번 / 1번.
3. **코인**: 인형 6 · 황금 20 · 하루 상한 30 · 도감 완성 100(추천, 하루 가치 열심 약 26 · 보통 약 8). 사냥만큼(열심 약 90) 올리려면 인형 18 · 하루 90.
4. **집게권**: 몬스터 사냥 공과 별개(추천) · 하루 최대 3장 · 보관 6장.
5. **황금 인형**: 넣기(추천, 판마다 25%) / 빼기. 이벤트 인형은 나중에 계절마다.
