# 모든 펫의 야차전 특기 (V13.185)

선생님 결정: 전설 · 신화 · 한정 펫에도 특기를 준다. 세기는 **기본 ≈ 영웅 < 전설(약 +6%) < 신화(약 +6%)**, 한정은 기본 정도.
(학생 피드백: 영웅은 특기가 있는데 전설 · 신화는 없어서 야차전에서 전설이 영웅보다 약했다.)

- 새 효과 종류는 없다. 기존 계열(바로 피해 · 다음 공격 강화 · 막기 · 회복 · 독)의 조합만. 게이지는 모두 3연속 정답.
- 숫자 합만 키우지 않고 `node server/pet-sim.mjs tiers 300`(실제 엔진, 펫 쌍마다 300판 × 두 모드)으로 승률을 맞췄다.
- 검사: `server/pet-skills-all-check.mjs`(빠른 판 수로 같은 승률 범위 확인).

## V13.195 곤충 · 공룡 시리즈 12종 (시리즈 알에서만)

시리즈 안 등급으로 같은 규칙을 따른다: **시리즈 기본 ≈ 기본 펫, 시리즈 영웅 ≈ 영웅 펫, 시리즈 전설 렉스 = 영웅 +약 6%**(전설 규칙).
숫자는 렉스만 새 조합이고, 나머지는 승률이 검증된 지금 펫의 조합을 그대로 썼다(docs/bug-dino-pets-design.md 표).
