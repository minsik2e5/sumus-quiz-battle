SUMUS VOCA스토어 없이, 홈 화면에 바로 설치

1분이면 앱처럼 설치돼요

설치하면 홈 화면 아이콘으로 바로 열리고, 주소창 없이 넓게 보여요. 선생님 공지와 공부 알림도 받을 수 있어요.

이미 앱으로 열려 있어요! 🎉

SUMUS VOCA 시작하기
  1. Safari로 열기이 페이지를 Safari에서 열어 주세요. (카카오톡 안이라면 오른쪽 아래 ⋯ → Safari로 열기)
  2. 공유 버튼 누르기화면 아래(또는 주소창 옆)의 버튼을 눌러요.
  3. "홈 화면에 추가"목록을 아래로 내려 홈 화면에 추가를 누르고, 오른쪽 위 추가를 눌러요.
  4. 홈 화면의 SUMUS 아이콘으로 열기이제부터는 아이콘으로 열어요. 알림은 앱 안의 나 → 알림 켜기에서 켤 수 있어요.

지금은 Safari가 아닌 것 같아요. 주소를 복사해서 Safari에 붙여 넣어 주세요.

  1. 크롬으로 열기이 페이지를 Chrome(또는 삼성 인터넷)에서 열어 주세요.
  2. 메뉴 누르기오른쪽 위 ⋮ 버튼을 눌러요. (삼성 인터넷은 아래 ≡)
  3. "앱 설치" 또는 "홈 화면에 추가"눌러서 설치를 선택해요.
  4. 홈 화면의 SUMUS 아이콘으로 열기알림은 앱 안의 나 → 알림 켜기에서 켤 수 있어요.

설치했어요! 홈 화면에서 SUMUS 아이콘을 찾아보세요.
