# SUMUS QUIZ BATTLE V0.9.2B — RUN MOTION UPGRADE

## Scope

V0.9.2B is a presentation-only RUN upgrade on top of the production V0.9.2A baseline (`5c3b02f`). It does not change battle rules, scoring, distance/rank source-of-truth, finish conditions, question lifecycle, WebSocket transport, reconnect/recovery, textbook/range data, or teacher/student gameplay behavior.

## Added

### `client/run-motion.js`

- RUN stride cycle and vertical bob motion
- READY → 3 → 2 → 1 → GO presentation sequencing on the existing countdown DOM
- one GO impact shake
- correct-answer acceleration lean and short trail streaks
- wrong/PASS dip feedback
- combo x3 ring and x5 teal trail treatment
- rank-change flip/nameplate flash and overtake speed lines
- queued rank callouts instead of simultaneous stacked callouts
- final-sprint atmosphere, HUD emphasis, and banner treatment
- finish ribbons, celebration exit, and finished-runner nameplate de-emphasis
- 2nd → 3rd → 1st podium entrance timing
- reduced-motion fallback
- `window.SUMUS_MOTION_AUDIT` for browser QA telemetry

### `client/premium-director.js`

- stadium roof/depth treatment
- crowd texture and floodlight structures
- SUMUS Academy broadcast ribbon
- refined track surface
- enlarged runner artwork without changing race distance or lane math
- compact identity-accented nameplates
- refined RUN HUD / LIVE TOP / finish gate
- final-sprint stadium tone transition

### QA

- `scripts/motion-qa.js`
- `npm run test:motion`
- `.github/workflows/v092b-qa.yml`
- build-time frozen-gameplay assertions for both new presentation modules
