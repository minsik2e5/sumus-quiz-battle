# SUMUS ISLAND

PART 1 퀴즈쇼 (`/host`) · PART 2 무궁화 꽃이 피었습니다 (`/mg`) · 학생은 `/play` 하나로 입장 (방 번호에 따라 자동 연결)

## 수업 방 — 한 방 번호로 PART 1 ↔ 2 ↔ 3 마음대로 오가기
1. 홈(`/`)에서 세 게임의 설정과 **먼저 시작할 게임**을 고르고 `수업 방 열기`
2. 학생은 QR 또는 `/play?pin=번호`로 **한 번만** 입장
3. 선생님 화면 오른쪽 위 **① 퀴즈쇼 · ② 무궁화 · ③ 줄넘기** 버튼으로 언제든 다른 게임으로 — 방은 그대로, 학생 화면도 함께 넘어가고 이름·색도 유지됩니다
- 진행 중에 넘기면 그 게임은 처음 상태(대기실)로 돌아가요. 다시 돌아오면 새로 시작
- 늦게 온 학생도 `/play`로 들어오면 지금 진행 중인 게임으로 자동 연결
- 한 게임에서 내보낸 학생은 다른 게임에서도 빠짐
- 홈의 `문제 편집`으로 문제만 고치고 돌아올 수 있음. 홈에 다시 오면 `이어서 하기`로 진행 중인 수업 방에 복귀 (같은 브라우저 탭)
- 선생님 화면(`/host`, `/mg`, `/jr`)은 수업 방 안에서만 열려요. 주소를 직접 열면 홈으로 이동
- 조작 창(듀얼 모니터)은 퀴즈쇼 전용

## PART 1 — 퀴즈쇼

정답 구역으로 캐릭터를 옮기는 실시간 교실 퀴즈. 선생님 PC(빔프로젝터) + 학생 휴대폰.

## 1. 학원 PC에서 바로 쓰기 (같은 와이파이)
1. Node.js LTS 설치: https://nodejs.org
2. 폴더 안 `실행하기.bat` 더블클릭 → 처음 한 번 설치 후 홈 화면이 자동으로 열림
3. 학생은 화면의 QR을 찍거나 주소(`http://PC주소:3000/play`)로 접속
   - 학생 폰이 **PC와 같은 와이파이**여야 함 (LTE 불가)
   - Windows 방화벽 창이 뜨면 "허용" 체크

## 2. 인터넷 주소로 쓰기 (Render 배포 — LTE도 접속 가능)
- GitHub에 올린 뒤 Render에서 Web Service 생성
- Build Command: `npm install` / Start Command: `npm start`
- 선생님: `https://주소/host`, 학생: QR 또는 `https://주소/play`
- 무료 플랜은 15분 미사용 시 잠듦 → 수업 전에 한 번 열어두기

## 즉석 문제 (게임 중 바로 출제)
- 대기실 · 정답 공개 후 · 결과 화면에서 `즉석 문제` 버튼 또는 **Q** 키
- 보기 칸 입력 → 번호 동그라미 눌러 정답 지정 → **Ctrl+Enter** 출제 (Alt+1~4로도 정답 지정)
- 문제 칸을 비우면 "문제를 잘 들어 보세요!"로 표시 → 말로 묻거나 칠판에 쓸 때
- `O / X`, `번호만`(1번~4번) 버튼으로 보기 한 번에 채우기
- `목록에도 저장`을 켜면 다음에 다시 쓸 수 있게 문제 목록에 추가
- 준비한 문제 없이 방을 열고 즉석 문제만으로 진행해도 됨

## 듀얼 모니터 — 조작 창
- 프로젝터 화면 오른쪽 위 `조작 창 열기` → 새 창을 선생님 모니터로 옮겨서 사용
- 조작 창: 현재 문제 + 정답 + 구역별 인원, 진행 버튼(Space), 즉석 문제(Ctrl+Enter), 학생 내보내기/탈락자 살리기
- 조작 창이 연결되면 프로젝터에서는 조작 버튼·즉석 문제 패널이 사라져 학생에게 정답이 노출되지 않음
- 팝업이 막히면 주소창 오른쪽 팝업 차단 아이콘에서 허용

## 문제 입력
- 한 문제당 보기 2~4개, 보기마다 사진 가능, 제한 시간 5~30초
- "한 번에 붙여넣기": `abandon의 뜻은? | *버리다 | 얻다 | 10` (정답 앞 `*`, 끝 숫자 = 초)
- 엑셀 표 복사도 가능: 문제 / 보기들 / 정답번호 / 시간
- 문제는 브라우저에 자동 저장. "파일로 저장"으로 세트별 백업

## 게임 방식
- 서바이벌: 틀린 구역·구역 밖 = 물에 빠져 탈락. 전원 오답이면 아무도 탈락 안 함. 1명 남거나 문제 끝나면 종료
- 점수전: 탈락 없음, 정답 구역 +100점, 최종 순위
- 진행: Space = 바로 정답 공개 / 다음 문제
- 대기실의 "봇 10명 추가"로 혼자 미리 테스트 가능


## PART 2 — 무궁화 꽃이 피었습니다
- 선생님: `/mg` → 잡히면(탈락/출발선으로), 제한 시간, 시작 난이도 선택 → 방 열기
- 학생: 버튼을 꾹 누르면 달리고 떼면 멈춤. 술래(문어)가 볼 때 누르고 있으면 잡힘
- 두 바퀴마다 난이도 상승(최대 5): 빨라짐 → 막판 가속·뜸 들이기 → 3단계부터 꽃게 술래 → 4단계부터 두 번 돌아보기


## PART 3 — 단체 줄넘기
- 양쪽 끝의 큰 술래들이 줄을 돌리고, 학생 전원이 **동시에** 줄이 땅을 스치는 순간 뛰어넘어요. 폰의 큰 버튼을 눌러 점프(착지 후 잠깐 쉬어야 다시 뜀)
- 6단계: 워밍업 → 박자 맞추기 → 따-따-다(짧-짧-길) → 점점 빨라져요 → 뜸 들이기(줄이 정점에서 멈칫) → FINAL. 단계마다 줄 속도·체공 시간·박자가 어려워짐
- 걸리면 `탈락`(바다로 풍덩) 또는 `하트 3개`. 타이밍이 정점에 가까우면 PERFECT(+50점), 연속 성공은 콤보
- 판정은 서버 시계 기준(폰이 누른 시각을 보냄)이라 와이파이 지연이 있어도 공정
- 규칙·통신 규약: `docs/jr-protocol.md`

## 이동이 부드러운 이유 (v2)
- 내 캐릭터는 폰에서 직접 움직이고(가속·감속 포함) 위치만 서버에 알려요 → 입력 지연 없음. 서버는 속도 제한만 검사해 순간이동을 막음
- 서버는 40Hz로 계산해 20Hz로 위치를 보내고, 화면은 서버 시간 기준으로 약 0.1초 전 위치를 이어 붙여 그려요(스냅샷 보간) → 와이파이가 흔들려도 뚝뚝 끊기지 않음

## PART 4 — 바나나킥
- 학생 전원이 **자기 캐릭터로 골키퍼**가 되어, 폰의 **좌우 버튼**으로 같은 슛을 동시에 막아요. 슈터는 섬의 마스코트(문어·꽃게·바다거북·복어)가 랜덤으로 바뀌며 공을 차요
- 방식: **탈락**(한 골 먹으면 탈락, 마지막까지 남는 학생이 우승) / **점수전**(1·2·3분 동안 가장 높은 점수)
- 난이도는 시간이 지날수록 연속으로 올라가요: 공이 빨라지고 → 더 휘어지고(바나나킥) → 2~3개 연속 슛 → 막판에 꺾이는 너클볼
- 서버가 만드는 슛은 항상 이론상 막을 수 있게(이전 슛 도착 위치에서 골키퍼 속도로 닿을 수 있게) 배치돼요
- 골키퍼 움직임은 서버와 폰이 같은 계산(`public/bk-common.js`)을 써서, 폰에서 보이는 위치가 곧 판정 위치예요
- 규칙·통신 규약: `docs/bk-protocol.md`
